# 書き出し

左上の **プロジェクト**(フォルダーのアイコン) → **書き出し** で、ひとつの画面から書き出します。

![](img/export.png)

## タブ

| タブ | 出すもの |
|---|---|
| **連番** | 動画(MP4・MOV)または連番画像 |
| **画像** | いまのフレーム1枚(PNG・JPG・PSD・BMP・TGA・TIFF・WEBP) |
| **セル** | 絵1枚 = ファイル1枚、それにタイムシート・カット袋 |
| **コンテ用紙** | コンテ用紙を PDF(ベクター)または PNG・JPG で |

## 連番(動画)

| 項目 | 内容 |
|---|---|
| 名前 | ファイル名(連番画像は命名ルール) |
| 形式 | 連番画像・**MP4**(H.264・H.265)・**MOV**(H.264・ProRes Proxy・LT・422・HQ・4444) |
| コーデックの設定 | ビットレート・画質・チャンネル・背景(白 / 黒 など) |
| 範囲 | **カット**(いまのカット) / **プロジェクト**(すべてのカット) |
| サイズ | **カメラ**(カメラフレーム) / **キャンバス** / **キャンバス（カットごと）** |
| 音声 | **SEミックスを動画に多重化** — SE の行の音をいっしょに入れる(ミュートした行は除く) |
| オプション・レイヤーFX | FXオン / 基本のみ / FXオフ |
| IN / OUT | プレビューで出す区間 |

- この機器で使えないコーデックは、オフの状態で表示されます。このパソコンの PATH に **FFmpeg** があれば、それで出せます。
- 書き出している間は画面の設定がロックされ、**キャンセル** だけ押せます。キャンセルしても、それまでの映像は残します。

## セル

絵1枚をファイル1枚で出します。タイムシートとカット袋もここで出します。

![](img/export-cels.png)

| 項目 | 内容 |
|---|---|
| セル形式 | PNG・JPG … |
| タイムシート形式 | PNG・JPG・XDTS |
| カット袋形式・サイズ | カットサイズ / 実寸用紙 |
| 書き出す種類 | セル・コンテ・美術・ディレクション・タイムシート・カット袋 |
| ラベル | [カラーラベル](/ja/layer-labels)とテイク(最新 / テイクn)で選ぶ — 例:原画の最新のテイクだけ |
| レイヤー | **基準**(本体のレイヤー)・**アタッチ**・**シートのみ**(タイムシートに載せた行)・カスタム |
| 命名 | フォルダ作成(プロジェクト / カット / レイヤー)・接頭辞・桁数・接尾辞 |
| 範囲 | カットを選んで(カットの格子でオン・オフ) |

- プレビューの下の一覧で、行ごと・絵ごとにオフ・オンします。
- 一覧の上の帯で、絵にディレクション・カメラパス・ガイドを重ねて出します。
- ファイル名はレイヤー名と絵の番号です(例:`A1.png`)。
- [アタッチレイヤー](/ja/attach-layers)は、本体のレイヤーと合成した1枚で出ます。
- [兼用カット](/ja/linked-cuts)はひとつのカットとして扱います。タイムシートはつながったカットごとに出ます。

## コンテ用紙

- **ベクターPDF**:文字・線を拡大しても粗くならない PDF。印刷・配布用。
- **ページ画像**:ページごとに PNG・JPG。

## プリセットとキュー

- **プリセット**:画面の横のプリセットの引き出しで **+ 現在の設定を保存** を押して、いまの設定に名前を付けておき、次に押して呼び出します。
- **キュー**:**キューに追加** で設定を複数積んでおき、**レンダーキュー** の引き出しで **すべてレンダー** を押して一度に出します(例:カットの動画 + セル + タイムシート)。

## 保存先

保存先は **[書き出し] を押したときに** たずねます。どの画面がいつ出るかは **機器** と **できるファイルの数** で決まります。[書き出し] の左の一行(「場所を指定してから書き出します」 / 「書き出したあとに場所を指定します」)が、この機器の順番です。

| 機器 | ファイル1枚<br>(画像・動画・コンテPDF …) | 複数・フォルダー<br>(セル・連番・コンテのページ画像 …) |
|---|---|---|
| **Windows・Mac・Linux** | 先に **ファイル保存画面** → 書き出し | 先に **フォルダー画面** → 書き出し |
| **iPad・iPhone** | 書き出し → 終わったら **書き出し画面** | 書き出し → 終わったら **書き出し画面**(フォルダーごと) |
| **Android** | 書き出し → 終わったら **ファイル保存画面** | 先に **フォルダー画面** → 書き出し |

- **フォルダー画面** は、ファイルではなくフォルダーをひとつ選ぶ OS の画面です。
- 名前の規則がカット・レイヤーごとにフォルダーを作るときは、1枚でも「複数・フォルダー」のほうです。
- 終わったあとに出る画面をキャンセルすると、結果を捨てずに **[選び直す]・[破棄]** をたずねます。
- **キュー**:先にたずねる機器は **キューに追加** のときに、あとでたずねる機器は **すべてレンダー** が終わったあとに一度たずねます。

### Google ドライブに直接書き出す

| 機器 | ファイル1枚 | 複数・フォルダー |
|---|---|---|
| **Windows・Mac** | できます — Google Drive デスクトップアプリが PC に作ったドライブのフォルダーを画面で選びます(Windows では多くの場合 **G:** ドライブ) | できます — 同じフォルダー |
| **Linux** | 同期ツールが作ったドライブのフォルダーを選びます | 同じ |
| **iPad・iPhone** | できます — 書き出し画面でドライブ | できます — 書き出し画面でドライブ(フォルダーごと) |
| **Android** | できます — ファイル保存画面でドライブ | **できません** — フォルダー画面にドライブがありません。この端末のフォルダーに書き出してから、同期アプリ(Autosync など)で合わせてください |

## 1枚だけすばやく

いまのフレーム1枚は、**プロジェクト** → **名前を付けて保存** → **PNG・JPG …** でも残せます。→ [開く・保存](/ja/files)
