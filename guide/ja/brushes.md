# ブラシ

## ブラシを選ぶ

![](img/tool-brush-library.png ':size=328')

ブラシツール<span data-k="tool-brush" data-k-paren></span>か消しゴム<span data-k="tool-eraser" data-k-paren></span>を選ぶと、**ツールライブラリ** にブラシの一覧が出ます。

- 左が **グループ** のタブ、その横がそのグループのブラシです。押すとそのブラシに切り替わります。
- 既定のグループ:基本・鉛筆・ペン・乾式画材・水彩・油彩・エアブラシ・色混ぜ・テクスチャ・デコレーション。
- ブラシをドラッグすると順番が変わります。別のグループのタブの上までドラッグして少し待つと、そのグループが開いて、そこへ移せます。
- グループとブラシごとにショートカットを付けられます(ブラシツール・消しゴムで別々)。→ [ショートカット](/ja/shortcuts)

## サイズと不透明度

カンバスの **左端にある縦長のピル** で変えます。

- いちばん上のチップ:**合成モード**(通常・背面・消去・比較（暗）・乗算 …)。
- **サイズ**(0.1〜2000 px)・**不透明度** のバー:ドラッグして変えます。± とマウスホイールは、[ツールサイズ](/ja/brushes?id=ツールサイズ)の段階に沿ってひと目盛りずつ動きます。
- 数値の横の **鉛筆ボタン**(数値を入力)を押すと、テンキーが開きます。最初のキーで元の値が置き換わり、✓ か <kbd class="k-pc">Enter</kbd><kbd class="k-mac">↩</kbd> で入力し、<kbd class="k-pc">Esc</kbd><kbd class="k-mac">⎋</kbd> でやめます。
- バーの下のカーブのボタンで、その値の **入り抜き**(筆圧・傾き・速度・ランダム、最小値・最大値)を決めます。
- ピルを上部のバーに移すには、**設定**(⚙) → **パネル** → **ブラシの値を上部のバーに**。

### ツールサイズ

![](img/panel-tool-size.png ':size=328')

右のバーの **ツールサイズ** パネルは、よく使うサイズ40個(0.7〜2000)の棚です。押すとそのサイズになります。サイズのバーをドラッグするときも、これらの値に吸い付きます。

## ブラシの設定

![](img/tool-brush-settings.png ':size=328')

**ツール設定** パネルに、いまのブラシの値がすべてあります。いちばん上のプレビューのストロークが、値を変えるたびに変わります。そのブラシに関係しない欄は表示されません。

| まとまり | おもな項目 |
|---|---|
| **インク** | 流量(+筆圧) |
| **ブラシ先端** | 先端の形(画像から先端を追加できます)・繰り返し方法・硬さ・アンチエイリアス・真円率・角度(線の方向・ペンの方向・ペン軸の回転・ランダム)・間隔 |
| **混色** | 下地混色 / ぼかし・絵の具量・絵の具濃度・色延び |
| **散布** | 散布 %・個数(1〜16)・両軸 |
| **質感** | デュアル先端(拡大率・濃度・合成)・質感(拡大率・濃度・乗算/高さ・濃度反転・明るさ・コントラスト) |
| **補正** | 角をとがらせる・手ブレ補正(0〜100、速度で補正)・描いた後に補正(0〜100、速度で調整・表示倍率で調整)・ベジェ曲線 |

変えた値はブラシごとに記憶され、ブラシを書き出すときにいっしょに出ます。

## 自分のブラシを作る

- 一覧の上の **＋**(現在の設定をプリセットとして保存) — いまの値を新しいブラシとして保存します。
- **⋯** メニュー:グループを新規作成・グループ名を変更・グループを削除・選択中のブラシ名を変更・選択中のブラシを削除・ブラシを書き出し・ブラシグループを書き出し・ブラシライブラリをリセット。表示のしかた(先端アイコン・ストロークのプレビュー・名前)もここで変えます。
- [切り抜きツール](/ja/tools?id=切り抜き)のスタンプで **先端として登録** すると、持ち上げている絵がブラシの先端になります。

## ほかのアプリのブラシを読み込む

**ブラシを読み込み** ボタンで選ぶか、ファイルをウィンドウにドラッグ&ドロップします。

| 形式 | アプリ |
|---|---|
| `.abr` | Photoshop (バージョン 6・7・10。とても古い 1・2 は読み込めません) |
| `.sut`・`.sutg` | CLIP STUDIO PAINT |
| `.anibrush` | Anicel(書き出したブラシ) |

## 筆圧

- ブラシごとの入り抜きは上のカーブのボタンで、**アプリ全体の筆圧カーブ** は[環境設定](/ja/preferences) → **入力** → **筆圧カーブ** で決めます。
- Windows で筆圧がおかしいときは、同じ場所の **Windows のタブレットサービス**(標準 / Wintab)を切り替えてみてください。
