# タッチとペン

すべて[環境設定](/ja/preferences) → **入力** で変えます。

![](img/prefs-input.png ':size=720')

## 指(カンバス)

| 指 | 既定の動作 | 選べるもの |
|---|---|---|
| 1本指ドラッグ | **めくり** — 左右で前・次の絵、上下で上・下のレイヤー | めくり（フレーム / レイヤー）・画面・ブラシサイズ・タッチで描画・なし |
| 2本指 | **画面** — 移動・拡大・回転 | |
| 3本指 | **ブラシサイズ** — 上下にドラッグ | |

- ドラッグの途中で **指をもう1本置く** と、一段細かくなります:めくりは1コマずつ、画面はズーム・回転が段階に吸い付き、ブラシサイズは[ツールサイズ](/ja/brushes?id=ツールサイズ)に吸い付きます(**追加指モディファイア**、既定はオン)。
- **タッチで描画** は1本指にだけ割り当てられます。ペンのない機器で指で描くときに使います。
- **タッチをすべて無視** をオンにすると、カンバスが指に反応しなくなります(ペンのみ)。

### タップ

| タップ | 動作 |
|---|---|
| 2本指タップ | 元に戻す |
| 3本指タップ | やり直す |
| 4本指タップ | 再生 / 停止 |

2本指・3本指の **長押し** には、好きな動作を割り当てられます。

### そのほかの項目

| 項目 | 内容 |
|---|---|
| フリップの触覚フィードバック | めくりが別の絵に着くたびに短く振動(振動子のある機器のみ) |
| 2本指の回転 | オフにすると、2本指は移動とズームだけを行います(回転のボタン・キーはそのまま) |
| モディファイアで回転をロック | オンにすると、追加の指が角度を固定します(移動 + 段階ズーム)。オフ(既定)では角度が段階に吸い付きます |
| 回転スナップ・ズームスナップ | 段階の値 |
| 最大ズームをロック | この倍率を超えて拡大しないように(画面に合わせるもここで止まります) |

## 指をキーの代わりに使う

キーボードのないタブレットでは、ペンで作業している間、**画面のどこかに置いた別の指** が <kbd class="k-pc">Shift</kbd><kbd class="k-mac">⇧</kbd>・<kbd class="k-pc">Alt</kbd><kbd class="k-mac">⌥</kbd> の代わりになります。

- ペンでドラッグしている間に指を置くと <kbd class="k-pc">Shift</kbd><kbd class="k-mac">⇧</kbd> — 移動は一方向に、図形は比率の固定が逆になります。ストロークを 45° でまっすぐにするには、**指ストロークモディファイア** をオンにします(既定はオフ)。
- 変形ボックスの角をドラッグするときに指を置くと <kbd class="k-pc">Alt</kbd><kbd class="k-mac">⌥</kbd> — 反対側の角を基準にサイズが変わります。

## ペンとマウスのボタン

| ボタン | 既定 | 選べるもの |
|---|---|---|
| 右クリック / ペンのサイドボタン | スポイト | スポイト・消しゴム・手のひら・元に戻す・やり直す・なし |
| ホイールクリック / ペンの上ボタン | なし | 〃 |
| ペンのお尻（ペンを裏返す） | 消しゴム | 〃 |

- ボタンを離したら元のツールに戻るか(**ツールに戻る**)、そのツールのままにするか(**保持**)を選びます。
- Apple Pencil のダブルタップ(ブラシ ⇄ 消しゴム)は、iPad のシステム設定に従います。

## 筆圧

- **筆圧カーブ**:アプリ全体の筆圧の反応。ブラシごとの反応は[ブラシ](/ja/brushes?id=サイズと不透明度)で。
- **Windows のタブレットサービス**:標準 / Wintab。筆圧が効かない・おかしいときは切り替えてみてください。
