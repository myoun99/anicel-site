# コンテレイヤー

カットのコンテを描くレイヤーです。カットごとにひとつ置きます。

![](img/conte-layer.png)

- タイムラインの **レイヤー ＋ ▾ → 絵コンテ** で追加するか、[コンテ](/ja/storyboard)パネルの **Conte** 行で、コンテレイヤーのないカットの区間の **＋** を押します。コンテレイヤーは ACTION のいちばん下にできます。
- ブロックひとつが[コンテ用紙](/ja/sheets)の画面ひとつです。ブロックの中で **フレーム ＋** を押すと、そこで画面が分かれます。
- 空きコマはありません。ブロックは次のブロックかカットの終わりまで続きます。
- カンバスで描くか、コンテ用紙に直接描きます。
- 同じトラックのカットどうしは、コンテレイヤーの名前・カラーラベル・不透明度・合成モード・FX の構成とアタッチの構成をいっしょに使います。画面と絵はカットごとに別です。
