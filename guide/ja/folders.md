# フォルダー

![](img/folder.png ':size=1188')

複数のレイヤーをまとめて、いっしょに表示・非表示にしたり、不透明度・合成モード・エフェクト・トランスフォームをいっしょにかけたりします。

## 作る・入れる

- **レイヤー ＋ ▾ → フォルダー** で空のフォルダーを作ります(名前は **Folder 1** …)。
- レイヤーの行をドラッグしてフォルダーの行の上に置くと、**そのフォルダーの中に** 入ります。ドラッグしてフォルダーの外に置くと出ます。
- フォルダーの中にフォルダーを入れられます。
- 名前の端の折りたたみボタンで、フォルダーを畳んだり広げたりします。

## フォルダーの行でできること

| 欄 | すること |
|---|---|
| 目 | 中のレイヤーをまとめて非表示 / 表示 |
| 不透明度 | フォルダー全体の不透明度 |
| 合成モード | 下の「通過とほかの合成モード」 |
| クリッピング | フォルダーごと下のレイヤーでクリッピング |
| FX・レーン | フォルダー全体に[エフェクトとトランスフォーム](/ja/effects) |

- フォルダーには絵を描きません(コマがありません)。
- 変形ツールでフォルダーを選ぶと、中のレイヤーがすべていっしょに動きます。
- フォルダーはコピー・貼り付けができません。

## 通過とほかの合成モード

- **通過**(既定):フォルダーがないかのように、中のレイヤーがひとつずつ下の絵と合成されます。中の[調整レイヤー](/ja/adjustment-layers)は、フォルダーの外の下のレイヤーにも効きます。
- **通常・乗算 …**(通過以外):フォルダーの中をまず1枚にまとめてから、その1枚を選んだ方式で下と合成します。中の調整レイヤーは、フォルダーの中だけに効きます。
