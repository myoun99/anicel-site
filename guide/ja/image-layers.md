# 画像レイヤー

背景などの画像をレイヤーとして置きます。

![](img/overview-cut2.png)

- 左上の **プロジェクト**(フォルダ) → **ファイルを開く…** で画像を選ぶか、ファイルをウィンドウにドラッグ&ドロップすると、**インポート** 画面が開きます。行ごとに **配置先**(新規レイヤー・新規カット・メディア)を決めて **インポート** を押すと、いまのカットに画像レイヤーができます。
- 読み込んだファイルは[メディアプール](/ja/media-pool)にも登録されます。**ラスタライズ** をオンにして読み込むと、絵として焼き込み、プールには残しません。
- `A1.png`・`A2.png` のように番号が続く絵は、ひとつ選ぶだけで、全部がひとつのレイヤーのフレームとして入ります。範囲はプレビューの IN/OUT で選びます。
- PSD はレイヤーをそのまま生かして読み込みます。
- ファイルのまま置かれた画像レイヤーは、レーンのいちばん上の **参照**(位置・スケール・回転)で置く場所を決めます。変形ツールでその行をつかむと、カンバスにボックスが出ます。
