# アニメーションレイヤー

コマごとに絵を描いて動かす、基本のレイヤーです。新しいプロジェクトの **A** がこのレイヤーです。

![](img/timeline.png)

## ブロックとコマ

- 横の1コマが1フレームです。色の付いた **ブロック** ひとつが絵一枚で、ブロックの長さがその絵の表示されるコマ数です。
- ブロックの中の大きい数字が **絵の名前**、ブロックの端の小さい数字が **長さ** です。
- ブロックのないコマは **空きコマ**(何も表示されない、シートの ×)です。
- 新しいレイヤーには **A・B・C …** と名前が付き、カラーラベルは **レイアウト上がり** で始まります。→ [カラーラベルとテイク](/ja/layer-labels)

## 絵を作る

- コマを選んで **フレーム** のピルの **＋** 新規フレーム<span data-k="frame-new-drawing" data-k-paren></span>:そのコマに新しい絵。ブロックの途中で押すと、ブロックがそこでふたつに分かれます。
- **✦**(フレーム自動生成)をオンにしておくと、空きコマに描くだけで絵ができます。
- ブロックの端の三角をドラッグすると長さが変わります。選んだブロックすべての長さは **1・2・3・4・N** コマ<span data-k="timeline-comma-1 timeline-comma-2 timeline-comma-3 timeline-comma-4 timeline-comma-n" data-k-paren></span>でまとめて決めます。後ろのブロックは、そのぶん詰まったり送られたりします。
- **押し出し / 詰め** は、選んだ位置に空きコマを開けたり詰めたりします。
- **×**(空にする)は、選んだコマを空きコマにします。

## 同じ名前 = 同じ絵

- 絵の名前が同じブロックは **同じ絵** です。片方を直すと、もう片方も変わります(シートのリピート表記と同じです)。
- ブロックの名前をすでにある名前に変えると、**リンクするフレーム** をたずねます。
- **リンクして貼り付け**<span data-k="edit-paste-linked" data-k-paren></span>は同じ絵として、**独立して貼り付け**<span data-k="edit-paste-independent" data-k-paren></span>は新しい絵として貼り付けます。リンクを切り離すには **リンクから独立**。→ [タイムライン](/ja/timeline?id=共用のピル)
- **自動命名** は、選んだブロックに開始番号から順に名前を付けます。

## まとまりの端の ＋ とホールド・リピート

空きコマなしでつながったブロックの **まとまり** の両端に、小さな **＋** と性質の表示が付きます。

- **＋**:押すと端に絵を1枚足し、ドラッグするとドラッグした分だけ何枚も足します。
- 性質の表示を押すと、まとまりの外の空きコマをどうするかを選びます。結果はカットの終わり(または始め)まで **薄いブロック** で埋められます。

| 性質 | すること |
|---|---|
| なし | 空きコマのまま |
| **ホールド** | 最後の絵がカットの終わりまでそのまま表示されます |
| **リピート** | まとまり全体がカットの終わりまで繰り返されます |
| **選択範囲をリピート** | まとまりのうち選んだ部分だけが繰り返されます(範囲を選んでいるとき) |

薄いブロックは、まとまりに合わせて自動で計算し直されます。まとまりを直したり、カットの長さを変えたりすると、それに合わせて変わります。

## 中割りマーク

動画(中割り)の指示用の印です。○ と ● の2種類があります。

- **○ 中割りマーク1・● 中割りマーク2**:選んだコマに付けたり消したりします。
- **中割りマークを自動追加**:間隔 n と ○/● を決めると、選んだブロックに頭から n コマごとに付けます。
- **名前を付けていない絵** は、ブロックの頭に名前の代わりにマークが表示されます。○・● のどちらで表示するかは、[環境設定](/ja/preferences) → **表示** → **名前のないブロックのマーク** で選びます(自動追加の画面も、最初はこのマークで開きます)。
