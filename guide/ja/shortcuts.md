# ショートカット

既定のキーです。矢印と **W A S D** は同じ働きをします。

## 移動

| 操作 | キー |
|---|---|
| レイヤーを上へ | <kbd>↑</kbd> または <kbd>W</kbd> |
| レイヤーを下へ | <kbd>↓</kbd> または <kbd>S</kbd> |
| 前のブロック | <kbd>←</kbd> または <kbd>A</kbd> |
| 次のブロック | <kbd>→</kbd> または <kbd>D</kbd> |
| 前のフレーム | <kbd>Shift</kbd> + <kbd>←</kbd> または <kbd>Shift</kbd> + <kbd>A</kbd> |
| 次のフレーム | <kbd>Shift</kbd> + <kbd>→</kbd> または <kbd>Shift</kbd> + <kbd>D</kbd> |

## コマ数

| 操作 | キー |
|---|---|
| 1コマに設定 | <kbd>1</kbd> |
| 2コマに設定 | <kbd>2</kbd> |
| 3コマに設定 | <kbd>3</kbd> |
| 4コマに設定 | <kbd>4</kbd> |
| Nコマに設定… | <kbd>5</kbd> |

- タイムライン・コンテパネル上部の **1 2 3 4 N** ボタンと同じです。選んだブロックすべて(選んでいなければいまのブロック)の長さを変え、後ろのブロックはそのぶん詰まったり送られたりします — `1--2--3--` をすべて選んで <kbd>1</kbd> を押すと `123` になります。
- <kbd>5</kbd> はコマ数を直接入れる画面を開きます。

## 再生

| 操作 | キー |
|---|---|
| 再生 / 一時停止 | <kbd>Shift</kbd> + <kbd>X</kbd> |
| 先頭へ | <kbd>Shift</kbd> + <kbd>Z</kbd> |

## 表示

| 操作 | キー |
|---|---|
| ズームイン | <kbd>Shift</kbd> + <kbd>E</kbd> |
| ズームアウト | <kbd>Shift</kbd> + <kbd>Q</kbd> |
| オニオンスキンの切り替え | <kbd>Q</kbd> |
| アクティブレイヤーをソロ | <kbd>T</kbd> |

| 操作 | キー |
|---|---|
| 編集([編集ボタン](/ja/timeline?id=編集ボタン)) | <kbd>X</kbd> |
| ブラシツール | <kbd>B</kbd> |
| 消しゴムツール | <kbd>E</kbd> |
| スポイトツール | <kbd>I</kbd> |
| 塗りつぶしツール | <kbd>F</kbd> |
| ガイドツール | <kbd>G</kbd> |
| 投げ縄選択 | <kbd>Z</kbd> |
| 投げ縄カット | <kbd>C</kbd> |
| スタンプ | <kbd>V</kbd> |
| 通常変形 | <kbd>Ctrl</kbd> + <kbd>T</kbd> |
| 自由変形 | <kbd>Ctrl</kbd> + <kbd>Y</kbd> |

- Mac・iPad では <kbd>Ctrl</kbd> の代わりに <kbd>⌘</kbd> です。

## 知っておくこと

- **Xシートでは方向キーがシートに沿って回ります。** タイムライン上部の右端の **⇄** で Xシート(縦表示)に切り替えると、<kbd>↑</kbd> <kbd>↓</kbd>(W S)が前・次のブロック、<kbd>←</kbd> <kbd>→</kbd>(A D)が下・上のレイヤー、<kbd>Shift</kbd> + <kbd>↑</kbd> <kbd>↓</kbd>(W S)が前・次のフレームになります。
- **再生・先頭へ・編集・コマ数のキーは、最後に触ったパネルのボタンを押します。** [コンテ](/ja/storyboard)パネルでは、再生はトラック全体を再生し、先頭へはトラックの先頭へ移り、編集はカーソルのあるブロックの画面を開き(カットならカット名)、コマ数はそのブロックの長さを変えます(カットブロックならカットの長さ)。
- **どのキーも変えられます。** 左上の **設定**(歯車) → **キーボードショートカット…** で一覧を見て変えます。自分で変えたキーが既定より優先されます。
