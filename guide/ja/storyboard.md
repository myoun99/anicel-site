# コンテパネル

作品全体の **カットを並べた** パネルです。タイムラインがカットひとつの内側だとすれば、コンテパネルはカットとカットをつなぐ外側です。カットごとにサイズが違っても、続けて再生します。タイムラインパネル下部のタブで切り替えます。

![](img/storyboard.png)

## コンテパネルの行

| 行 | 内容 |
|---|---|
| **Camera**(カメラ) | カットごとのカメラのキーと動き(PAN・T.U・T.B) |
| **Transition**(トランジション) | FI・FO・O.L のような画面転換 |
| **Video**(映像トラック) | ブロックひとつが **カットひとつ** |
| **Conte**(絵コンテ) | カットごとの[絵コンテレイヤー](/ja/conte-layer)。コマひとつが[コンテ用紙](/ja/sheets)の1コマ |
| **S1・S2 …** | [SE](/ja/sound-layers) — カットをまたぐ音もひとつのブロックで |

## カットを扱う

- **Video** の行でカットを選び、ドラッグして順番を変え、端をドラッグして長さを変えます。
- 新しいカットは **カット** のピルの **＋**、複製・削除は **共用** のピルの **複製**・**削除** です。
- カットをダブルクリック(または **編集**)すると、カット名を変えられます。
- [兼用カット](/ja/linked-cuts)は、カット名の横に 🔗 が付きます。

## コンテを描く

- **Conte** の行で、絵コンテレイヤーのないカットは **＋** で作ります。
- コマを選んで長さを変え、ブロックをダブルクリックするとコマの名前を変えられます。絵がまだないコマは薄く表示されます。
- 絵はカンバスか[コンテ用紙](/ja/sheets)パネルで描きます。

## O.L(オーバーラップ)

- O.L はふたつのカットにまたがるので、タイムラインではなく、ここの **Transition** の行で編集します。種類は **編集**、長さはブロックの端をドラッグして決めます。
- O.L の間は、カメラの行が前後のカットのふたつに分かれて表示されます。

## 再生

コンテパネルで **▶** を押すと、**すべてのカットを続けて** 再生します(タイムラインではいまのカットだけ)。→ [再生と録音](/ja/playback)

## 知っておくこと

- 映像トラックはひとつです。
- 行はレールでドラッグして順番を変えます(CAM のセクションは順番が固定)。
- ソロ・表示のメニューはタイムラインと同じです。→ [レイヤーの概要](/ja/layers)
