# オニオンスキン

前後の絵を薄く重ねて見ながら描きます。**レイヤーごと** にオンにします(全体のスイッチはありません)。

| オンにする場所 | |
|---|---|
| ![](img/icon-rail-onion-skin-button.png ':class=icon :no-zoom') ツールバー上部 | いまのレイヤー<span data-k="onion-skin-toggle" data-k-paren></span> |
| レイヤーの行の **オニオンスキン** の欄 | そのレイヤー。押したまま上下になぞると複数の行を一度に |
| レールの見出し行のオニオンスキンの欄 | **表示中のレイヤーにオニオンスキンを適用 / 表示中のレイヤーのオニオンスキンを解除** |

アニメーション・絵コンテ・ディレクションのレイヤーで使えます。

## オニオンスキンパネル

| | |
|---|---|
| ![](img/icon-rail-group-rail-R4.png ':class=icon :no-zoom') | 右のバーのボタン(ツールサイズと同じボタン)。ここで決めたことはアプリの設定なので、すべてのプロジェクトに同じように適用されます |

![](img/panel-onion-skin.png ':class=panel')

- 中央の ● がいまの絵、左が **前**(以前)の8枚、右が **後**(以後)の8枚です。
- **バーの高さ = 濃さ**。上下にドラッグして変えます(最初の値は前 40%・後 30%)。
- バーの下の番号を押すとその1枚だけオフ、もう一度押すと元の濃さに戻ります。

| 上部のボタン | 選ぶもの |
|---|---|
| **ブロック** / **フレーム** | 1段が絵1枚か、1フレームか |
| **色** / **絵** | ゴーストを決めた色で / 絵の色のまま |
| **その場**(最初の値) / **最前面** | 各レイヤーの絵のすぐ下に挟む(上のレイヤーに隠れ、そのレイヤーの合成モード・フォルダー・クリッピングに従う) / すべてのレイヤーの上に |
| 赤・緑の丸 | Colors のとき、前・後の絵に付ける色 |

## ほかのレイヤーを透かして見るには

オニオンスキンは、そのレイヤー自身の前後の絵を表示します。ほかのレイヤーの絵を下絵として見るには、そのレイヤーを表示したまま **不透明度** を下げてください。
