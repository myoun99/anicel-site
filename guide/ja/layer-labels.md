# カラーラベルとテイク

レイヤーごとに **工程**(コンテ・レイアウト・原画・動画 …)を付けると、行とブロックにその工程の色が塗られます。どの段階の絵なのか、タイムラインでひと目でわかります。

![](img/labels.png)

## ラベルを付ける

行のいちばん左の **カラーラベル** の欄を押して、工程を選びます。

| 工程 | チップの表記 | 選べる修正 |
|---|---|---|
| 用紙 | 用紙 | (なし) |
| コンテ | コンテ | 監督・総監督 |
| 美術 | 美術 | 演出・作画監督・総作画監督・監督・総監督・アクション作画監督 |
| レイアウト | LO | 〃 |
| ラフ原 | ラフ原 | 〃 |
| 原画 | 原画 | 〃 |
| 動画 | 動画 | 上の6つ + **動画検査** |
| 仕上げ | 仕上 | 上の6つ + **セル検査** |

- 工程を選ぶと、横に **上がり**(その工程の作業そのもの)と **修正** の段階が開きます。チップにはふたつが並んで「LO作監」のように書かれます。
- **ラベルなし** で消します。
- 新しいレイヤーは、種類に応じたラベルを持って作られます:アニメーション = レイアウト上がり、絵コンテ = コンテ上がり、画像 = 美術上がり。
- [アタッチレイヤー](/ja/attach-layers)は、本体のレイヤーのラベルを引き継ぎます。

## カットのラベル

カット全体にもラベルを付けます:タイムライン上部の **カット** のピルのメニュー → **レイヤーマーク**。[兼用カット](/ja/linked-cuts)どうしは同じラベルを使います。

## テイク

ラベルの右の欄は **テイク**(T1〜T9、最初は T1)です。同じ工程を描き直したときに番号を上げておきます。

## ラベルを使うところ

- **色をソロ**:レールの見出し行のカラーラベルの欄 → 選んだ工程の行だけを残します(**マークフィルターを解除** で戻す)。
- **書き出し**:[書き出し](/ja/export) → **セル** で、ラベル・テイク(最新 / テイクn)で書き出す行を選びます。
- **スタッフ**:**設定** → **作品設定**・カットの **カット設定** で、工程ごとに担当者を書きます。→ [タイムシート・コンテ用紙・カット袋](/ja/sheets)
