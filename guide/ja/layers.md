# レイヤーの概要

タイムラインでは、**一行がひとつのレイヤー** です。行は3つのセクションに分かれ、左の縦の帯にセクション名が書かれています。

| セクション | 画面の位置 | 入るレイヤー |
|---|---|---|
| **CAM**(カメラ) | いちばん上 | カメラ・トランジション・ディレクション |
| **SE**(効果音・セリフ) | 中ほど | SE |
| **ACTION**(絵) | 下 | アニメーション・絵コンテ・画像・フォルダー・調整レイヤー |

セクション名は、紙のタイムシートの欄の名前と同じです。[Xシート](/ja/timeline?id=xシート)に切り替えると、紙のシートのように左から ACTION・SE・CAM の順で縦の列になります。

## レイヤーの種類

| 種類 | ひとこと説明 | 詳しく |
|---|---|---|
| **アニメーション** | コマごとに絵を描く基本のレイヤー | [アニメーションレイヤー](/ja/animation-layers) |
| **絵コンテ** | コンテの絵。ブロックひとつがコンテ用紙の1コマ | [絵コンテレイヤー](/ja/conte-layer) |
| **画像** | 背景のような絵1枚をカット全体に | [画像レイヤー](/ja/image-layers) |
| **フォルダー** | レイヤーをまとめて、いっしょに表示・非表示・移動する | [フォルダー](/ja/folders) |
| **調整レイヤー** | 下のレイヤー全体にエフェクト(明るさ・色相・ぼかし …) | [調整レイヤー](/ja/adjustment-layers) |
| **SE** | 音・セリフ。波形を見ながらタイミングを合わせる | [サウンド(SE)レイヤー](/ja/sound-layers) |
| **ディレクション** | PAN・FIX のようなカメラの指示をシートに書く | [カメラ・ディレクション・トランジション](/ja/camera-section) |
| **カメラ** | カメラワーク(位置・スケール・回転)。カットごとにひとつ、最初からある | 〃 |
| **トランジション** | FI・FO・O.L のような画面転換。トラックにひとつ、最初からある | 〃 |
| **アタッチ**(種類ではなく付け方) | 本体のレイヤーにくっついて、動き・エフェクトにいっしょに従うレイヤー(影・ハイライト) | [アタッチレイヤー](/ja/attach-layers) |

> 新しいレイヤーの既定の名前:アニメーションは **A・B・C …**、画像は **BG**(すでにあれば **BOOK**)、絵コンテは **Conte**、調整レイヤーは **FX1**、SE は **S1・S2**、ディレクションは **Direction 1**、フォルダーは **Folder 1**、カメラ・トランジションは **Camera**・**Transition**。業界の表記に合わせて、どの言語の画面でも同じ名前です。

## レイヤーを作る

タイムライン上部の **レイヤー** のピルで作ります。

- **＋** 新規レイヤー<span data-k="layer-add" data-k-paren></span>:アニメーションレイヤー。[コンテパネル](/ja/storyboard)では SE レイヤー。
- **＋ ▾**:種類を選んで作ります — アニメーション・絵コンテ・画像・SE・ディレクション・調整レイヤー・フォルダー、それにいまのレイヤーの上/下に付く **フリー / シンクのアタッチレイヤー**。

## レイヤーの行の欄

![](img/layer-row.png ':size=465')

行の左(レール)に、左から次の欄があります。種類に合わない欄は空いています。

| 欄 | すること |
|---|---|
| **カラーラベル** | 工程(コンテ・原画・動画 …)。→ [カラーラベルとテイク](/ja/layer-labels) |
| **テイク** | T1〜T9 |
| **▸** | レーン(トランスフォーム・エフェクト …)を開きます。→ [エフェクトとトランスフォーム](/ja/effects) |
| **シートの矢印** | このレイヤーを[タイムシート](/ja/sheets)に載せるか・外すか |
| **種類のアイコン・名前** | 名前を **ダブルクリック** すると変えられます。名前の横に、リンク 🔗・グラフ・折りたたみのような小さなボタンが付くこともあります |
| **クリッピング** | 下のレイヤーでクリッピング(下のレイヤーの絵の中だけに表示) |
| **FX** | このレイヤーのエフェクトをまとめてバイパス / 適用 |
| **オニオンスキン** | このレイヤーのオニオンスキン。→ [オニオンスキン](/ja/onion-skin) |
| **目** | 非表示 / 表示 |
| **不透明度** | バーをドラッグして 0〜100% |
| **合成モード** | 合成のしかた(通常・乗算・スクリーン・オーバーレイ …)。フォルダーは **通過** が既定 |

- 目・オニオンスキン・クリッピング・FX・シートのような、オン/オフを切り替える欄は、**押したまま上下になぞる** と、通った行がすべて同じ状態に変わります。

### いちばん上の見出し行 (すべてのレイヤーにまとめて)

レールのいちばん上の行の各欄を押すと、その欄についてのメニューが開きます。

| 欄 | メニュー |
|---|---|
| セクション | SE行を表示・カメラ行を表示 |
| シート | すべてシートに載せる / すべてシートから外す・シートオンの行をソロ |
| カラーラベル | 色をソロ・マークフィルターを解除 |
| 種類 | 種類をソロ |
| クリッピング | クリッピングをすべて解除・クリッピングをソロ |
| FX | FXをすべて適用 / FXをすべてバイパス・FXオンの行をソロ |
| オニオンスキン | 表示中のレイヤーにオニオンスキンを適用 / 表示中のレイヤーのオニオンスキンを解除・オニオンスキンパネルを開く |
| 目 | すべて表示 / すべて隠す |
| 不透明度・合成モード | 表示中のレイヤー全体に |

**ソロ** は、条件に合う行だけを残して、ほかを一時的に隠します。もう一度押すと解除されます。

## 選ぶ・動かす・消す

- 名前を押すと、そのレイヤーが **いまのレイヤー**(描く場所)になります。ドラッグすると複数の行を選びます。
- 選んだ行をもう一度ドラッグすると **順番が変わります。** フォルダーの上に置くと、そのフォルダーの中に入ります。
- セクションをまたいで動かすことはできません(作画レイヤーを SE のセクションへ、など)。CAM のセクションは、上からカメラ・トランジション・ディレクションの順に固定で、ディレクションどうしだけ順番を変えられます。
- 複製・切り取り・コピー・貼り付け・削除は共用のピルで行います。→ [タイムライン](/ja/timeline?id=共用のピル)
- レイヤー名は **編集**<span data-k="edit-instance" data-k-paren></span>でも変えられます。複数の行を選んで編集すると、まとめて変わります。

## レイヤーにないもの

- **レイヤーのロック** はありません。
- **ライトテーブル** はありません。ほかの絵を透かして見るのは[オニオンスキン](/ja/onion-skin)で行います。
- **テキストレイヤー** はありません。文字は[テキストツール](/ja/tools?id=テキスト)で絵の中に入れます。
