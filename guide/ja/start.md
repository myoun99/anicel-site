# はじめて描いてみる

新しいプロジェクトを開いて絵を何枚か描き、再生して、保存するまでを順番に説明します。

![](img/overview.png)

## 1. 新しいプロジェクト

- アプリを起動すると、**無題 1** という新しいプロジェクトが開きます。別の新しいプロジェクトは、左上の **プロジェクト**(フォルダーのアイコン) → **新規プロジェクト** です。
- 新しいプロジェクトにはカットひとつ、作画レイヤー **A**、最初のコマの絵まで入っているので、すぐに描けます。
- 画面の中央が **カンバス**、下が **タイムライン**、左の縦のバーが **ツール** です。各部分の名前は[画面とパネル](/ja/screen)にあります。

## 2. 描く

- 左のツールバーで **ブラシツール**<span data-k="tool-brush" data-k-paren></span>を選び、カンバスに描きます。
- ブラシの種類は左上の **ツールライブラリ** パネルで選びます(基本・鉛筆・ペン・水彩 …)。詳しくは[ブラシ](/ja/brushes)。
- ブラシの **サイズ** と **不透明度** は、カンバスの左端にある縦長のピルで変えます。バーをドラッグするか ± を押し、数値の横の鉛筆ボタンで数値を直接入力します。
- 消しゴムは **消しゴムツール**<span data-k="tool-eraser" data-k-paren></span>、取り消しは <span data-k="edit-undo"></span> か、ツールバーのいちばん上の矢印です。
- 色は、右端の色ボタン(重なった丸がふたつ)を押して[色パネル](/ja/color)を開いて選びます。

## 3. 次の絵を作る

![](img/toolbar.png)

タイムラインでは、一行がひとつのレイヤー、横が時間(フレーム)です。色の付いた **ブロック** ひとつが絵一枚です。

- レイヤー **A** の行で絵を入れるコマを押し、タイムライン上部の **フレーム** の **＋** を押すと、そのコマに新しい絵ができます。
- **✦**(フレーム自動生成)をオンにしておくと、空いたコマに描くだけで絵ができます。
- 前の絵を透かして見ながら描くには、ツールバー上部の **オニオンスキンの切り替え**<span data-k="onion-skin-toggle" data-k-paren></span>をオンにします。→ [オニオンスキン](/ja/onion-skin)
- ブロックの端をドラッグすると、その絵が表示される長さ(コマ数)が変わります。

## 4. 再生

- タイムライン下部の **▶**(再生)で再生し、もう一度押すと止まります。ループ再生・カメラビュー・録音のボタンもそこにあります。→ [再生と録音](/ja/playback)

## 5. 保存

- **プロジェクト** → **保存**<span data-k="file-save" data-k-paren></span>で保存します。最初の保存で場所と名前を決め、ファイルは `.anicel` ひとつに保存されます。
- **自動保存は最初はオフになっています。** オフのままだと、保存せずに閉じた作業は残りません。オンにしておくと、決めた間隔(3〜60分)ごとにプロジェクトファイルそのものが保存されます。→ [環境設定](/ja/preferences) → **自動保存**
- もう一度開くには、**プロジェクト** → **ファイルを開く** か **最近使ったプロジェクト** です。ファイルをウィンドウにドラッグ&ドロップしても開きます。→ [開く・保存](/ja/files)
