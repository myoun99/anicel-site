# 色

| | |
|---|---|
| ![](img/icon-rail-group-rail-R1.png ':class=icon :no-zoom') | 右のバーのいちばん上のボタン。手前の丸 = **描く色**、奥の丸 = **背景色**(押すとふたつの色が入れ替わります) |

| カラーホイール | RGB | パレット |
|---|---|---|
| ![](img/panel-color-wheel.png ':class=panel') | ![](img/panel-color-rgb.png ':class=panel') | ![](img/panel-color-palette.png ':class=panel') |

- **カラーホイール** — 輪で色相、三角形で彩度・明るさ。下に **最近** の10色と **デフォルトのパレット** が付いています。
- いちばん下の行の16進数・R・G・B の数値を押すと直接入力できます。
- **パレット** — マスを押すとその色、**空いたマスを押すといまの色がそのマスに** 入ります。マスをドラッグすると位置が移ります。**−** はいまの色を外す、**⋯** に **デフォルトにする**(ホイール・RGB のタブの下に付くもの)・**複製**・**削除**。
- **最近** — ストロークに使った色が新しい順にたまります。

## ほかの場所から色を拾う

- [スポイト](/ja/tools?id=スポイト)<span data-k="tool-eyedropper" data-k-paren></span>、または描いている途中で <kbd class="k-pc">Alt</kbd><kbd class="k-mac">⌥</kbd> を押したままカンバスを押します。
- ペンのサイドボタン・マウスの右ボタンも、既定はスポイトです(変えるには[環境設定](/ja/preferences) → **入力**)。

## 描いた絵の色を変える

タイムラインの共用のピルの **色編集** で、選んだ範囲の絵をまとめて変えます。→ [タイムライン](/ja/timeline)

| 項目 | すること |
|---|---|
| 色変換 | 絵の色をいまの色に変えます(透明度はそのまま — 線の色の変更) |
| 色削除・色残し | いまの色の部分だけを消すか、いまの色だけを残して消します(許容値を調整) |
| ピクセル消去 | 絵を空にします |
| 2値化 | 半透明の縁をなくします — しきい値以上は不透明、未満は透明(色はそのまま) |
| ピクセル切り取り・ピクセルコピー・ピクセルを上に貼り付け・ピクセルを下に貼り付け | 絵の単位で動かす |
