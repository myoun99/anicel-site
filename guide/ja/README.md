# Anicel

手描きアニメーションの制作アプリです。プロジェクトひとつがファイルひとつです。
Windows・macOS・iPad・Android・Linux で同じファイルを開けます。

> ⚠️ 現在は開発中(非公開テスト)です。保存形式が予告なく変わることがあるので、実際の納品作業には使わないでください。

## できること

- ひとつのプロジェクトにカットをいくつも置き、カンバスサイズをカットごとに決めます — [カットごとのカンバスサイズ](/ja/canvas-size)
- レイヤー:アニメーション・絵コンテ・画像・フォルダー・調整・SE・ディレクション・カメラ・トランジション、そして本体に付くアタッチ — [レイヤーの概要](/ja/layers)
- レイヤーとカットにカラーラベル・テイクを付けます — [カラーラベルとテイク](/ja/layer-labels)
- タイムシート・コンテ用紙・カット袋を作業画面で見て、書き出します — [タイムシート・コンテ用紙・カット袋](/ja/sheets)
- 音のファイルを SE レイヤーとして置き、マイクで録音します — [サウンド(SE)レイヤー](/ja/sound-layers)・[再生と録音](/ja/playback)
- CLIP STUDIO(.sut)・Photoshop(.abr)のブラシを読み込みます — [ブラシ](/ja/brushes)
- TVPaint(.tvpp)・CLIP STUDIO(.clip)のファイルをプロジェクトとして開きます — [開く・保存](/ja/files)
- 動画(MP4・MOV)・連番画像・セル・タイムシート・コンテ用紙(PDF)に書き出します — [書き出し](/ja/export)
