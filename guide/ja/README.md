# Anicel

手描きアニメーションを、コンテから作画・タイムシート・音・書き出しまでひとつのファイルで作るアプリです。

## 強み

- **コンテを描けば、そのままカットになる** — [コンテ](/ja/storyboard)
- **タイムシート・コンテ用紙を、出力そのままの姿で見ながら作業** — [タイムシート・コンテ用紙](/ja/sheets)
- **工程が色でわかる** — [カラーラベル](/ja/layer-labels)
- **影やハイライトは本体の絵にくっつけて** — [アタッチレイヤー](/ja/attach-layers)
- **カットごとに違うカンバスサイズ** — [カットごとのカンバスサイズ](/ja/canvas-size)
- **音をレイヤーとして置き、波形を見ながらタイミング合わせ** — [サウンドレイヤー](/ja/sound-layers)
- **動画・セル・タイムシート・コンテ用紙まで、ひとつの画面から書き出し** — [書き出し](/ja/export)

はじめての方は[はじめに](/ja/start)からどうぞ。
