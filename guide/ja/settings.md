# プロジェクト設定

**設定**(⚙)メニューの上の二行は **このプロジェクトだけ** に適用されます(ファイルに保存)。アプリ全体に適用されるのは[環境設定](/ja/preferences)です。

## 作品設定

![](img/work-settings.png ':size=460')

- タイトル・話数は、タイムシート・コンテ用紙・カット袋の頭に記入されます。
- **表紙の絵** は[メディアパネル](/ja/media-pool)の画像から選びます。
- **スタッフ設定**:工程ごとの担当者。カットごとに違うときは **カット** のピル → **カット設定** で。

## プロジェクト設定

![](img/menu-project-settings.png ':size=496')

行ごとに今の値が見え、押すとその値を変える画面が開きます。

| 行 | |
|---|---|
| **FPS** | 音のあるプロジェクトで 23.976 ↔ 24 のように変えると、音をどうするかをたずねます:**音のタイミングを維持** / **音を0.1%プル** |
| **サンプルレート** | 44.1・48・96 kHz |
| **カメラ** | カメラフレームのサイズ(プロジェクト共通)。**キャンバスで調整** でカンバスの上でドラッグして決めることもできます。カンバス(描く用紙)のサイズはカットごとに別々 → [カットごとのカンバスサイズ](/ja/canvas-size) |
| **再生方式** | 絵が用意できていないフレームで:**すべてのフレーム**(既定)・**フレームを飛ばす**・**再生前にレンダリング** → [再生と録音](/ja/playback) |
