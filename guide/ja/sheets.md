# タイムシート・コンテ用紙・カット袋

作業した内容がすぐに紙の書式に記入されるので、**出力されるそのままの姿** を見ながら作業します。右のバーの同じボタンひとつに、3つのタブが入っています(最初から開いています)。

![](img/timesheet.png)

## 共通

- ページはパネル下の帯でめくります(前のページ・次のページ、またはページの数字をドラッグ)。
- 用紙上部の筆のボタン(**ブラシを許可**)をオンにすると、紙のように直接描けます。ブラシ・消しゴム・図形ツールで描き、ほかのツールで押すと用紙が動きます。
- [メディアパネル](/ja/media-pool)の画像を用紙のコマにドラッグ&ドロップすると、写真として入ります。ブラシを許可がオンなら、写真をつかんで動かし、サイズ・回転を変えます。
- 頭のタイトル・話数・カット・作画者の欄は、押してその場で直します。作品全体のタイトル・話数・会社ロゴ・表紙の絵・スタッフは、**設定**(⚙) → **作品設定** で決めます。
- 見えているとおりに[書き出し](/ja/export)されます。

## タイムシート

タイムラインとタイムシートは完全に同期します。タイムシートをリアルタイムで見ながら作業します。

| タイムラインの欄 | すること | タイムシートに記入されるもの |
|---|---|---|
| **ACTION** | 絵を描きます | ACTION 欄([カラーラベル](/ja/layer-labels)が動画の行は CELL 欄) |
| **SE** | [SE](/ja/sound-layers)の名前・セリフを決めたブロックを作ります | SE 欄に名前・セリフ |
| **CAM** | カメラと撮影指示を編集します | CAM 欄にカメラのキー名と動き(PAN・T.U・T.B)、[ディレクション](/ja/camera-section)・[トランジション](/ja/camera-section) |

- CAM 欄の動きと画面転換は、**メモ欄** にも固定テキストとして記入されます。コンテ用紙と同じ文から時間だけを除いたものです。メモ欄は左右2つで、左がいっぱいになると右の上から続きます。
- シートにどの行を載せるかは、レイヤーの行のシートの矢印で決めます。→ [レイヤーの概要](/ja/layers)
- 表示を2通りに切り替えられます:**表記シート**(リピート・止めのような文字で短く書く) / **データシート**(書き出すとおりに1コマずつ)。

**シート書式**

| 項目 | 内容 |
|---|---|
| シートの長さ | 1枚に 3秒 / 6秒 |
| 表示する枠 | 頭のタイトル・話数・シーン・カット・タイム・作画者・シートの枠のうち、表示するもの |
| 引き伸ばし線・ACTION / 引き伸ばし線・CELL | あり / なし + N — N コマ以上同じ絵(止め)か × が続くと、(N+1) コマ目から線を引く |
| セリフのない区間 | 塗る / 塗らない |
| 固定テキスト | 適用 / 非適用。全体設定と現在のカットの設定が別にあります |

## コンテ用紙

![](img/conte-paper.png)

[コンテパネル](/ja/storyboard)のタイムラインとコンテ用紙は完全に同期します。コンテ作業はタイムラインパネルへ移らず、コンテパネルで行います。

| コンテパネルの欄 | すること | コンテ用紙に記入されるもの |
|---|---|---|
| **Conte** | [絵コンテレイヤー](/ja/conte-layer)のブロックでコマを分けます | ブロックひとつが用紙の1コマ。コマの画面の欄に描くと、そのカットのコンテの絵になります |
| **CAM** | カメラと画面転換を編集します | コマの中のカメラの枠、内容欄の動き(PAN・T.U・FIX)・画面転換(FI・FO・O.L)。FI・FO は「カット頭」「カット尻」を付け、最初のコマのいちばん上・最後のコマのいちばん下に書きます |
| **SE** | セリフのブロックを作ります | セリフ欄に名前・セリフ |

**コンテ用紙書式**

| 項目 | 内容 |
|---|---|
| 様式 | アナログ / デジタル |
| 画面の黒枠 | あり / なし |
| 表紙・白紙 | 入れる / 入れない |
| 固定テキスト | 適用 / 非適用。全体設定と現在のカットの設定が別にあります |
| カメラワーク | コマを広げる / コマ内に収める。全体設定と現在のカットの設定が別にあります |

## カット袋

- カットごとの袋(カットの情報・スタッフ)を表示します。カットのスタッフは、**カット** のピル → **カット設定** で決めます。
- **カット袋書式** で様式を選びます。
