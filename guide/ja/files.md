# 開く・保存

左上の **プロジェクト**(フォルダーのアイコン)メニューで行います。

## プロジェクトファイル

- Anicel のプロジェクトは **`.anicel` ファイルひとつ** です。絵・タイムシート・音・設定がすべてこの中に入ります(音・映像を「リンク」にした場合は、元のファイルが別に必要です → [メディアパネルとインポート](/ja/media-pool))。
- 複数のプロジェクトを開くと、上部のバーにタブとして並びます。

## 開く

![](img/menu-project.png ':size=245')

**プロジェクト** → **ファイルを開く**(またはファイルをウィンドウにドラッグ&ドロップ)。何を開くかによって、行き先が自動で決まります。

| ファイル | 開く場所 |
|---|---|
| `.anicel`・`.tvpp`(TVPaint)・`.clip`(CLIP STUDIO PAINT) | 新しいプロジェクトのタブ |
| 画像・動画・音・PDF | [インポート画面](/ja/media-pool) |
| `.abr`・`.sut`・`.sutg`・`.anibrush` | [ブラシ](/ja/brushes)ライブラリ |
| `.ttf`・`.otf`・`.ttc` | フォント([テキストツール](/ja/tools)) |
| ほかのアプリのショートカットファイル | [ショートカット](/ja/shortcuts)のプリセット |

- **フォルダを開く**:カットフォルダー(画像ファイルの入ったフォルダー)を丸ごとインポート画面で開きます。
- **最近使ったプロジェクト**:最近開いたファイル。移動して見つからないファイルは、**再接続** で新しい場所を教えます。
- ファイルを[ビューア](/ja/screen)にドラッグ&ドロップすると、プロジェクトとしては開かずに、そのビューアに表示します。

### TVPaint・CLIP STUDIO のファイル

- `.tvpp` を開くと、レイヤー・タイミング・中割りの印が、Anicel のレイヤー・ブロック・マークに変わります。
- `.clip` を開くと、アニメーションセルがレイヤー・ブロックに、セルの中のレイヤーは[アタッチレイヤー](/ja/attach-layers)(A・A-1 …)として入ります。
- 元のファイルは変わりません。保存すると `.anicel` で保存されます。

## 保存

| メニュー | キー | 内容 |
|---|---|---|
| 保存 | <span data-k="file-save"></span> | 最初の保存のときだけ、場所と名前をたずねます |
| 名前を付けて保存 → プロジェクト(.anicel) | <span data-k="file-save-as"></span> | 別のファイルに |
| 名前を付けて保存 → PNG・JPG・BMP・TGA・TIFF … | | **いまのフレーム1枚** をカンバスサイズの画像で |

複数枚・動画・セルで書き出すのは[書き出し](/ja/export)です。

## 自動保存

**自動保存は最初はオフになっています。** オフのままだと、プロジェクトは保存したときだけ変わり、アプリが異常終了すると、最後に保存したあとの作業が消えます。

- [環境設定](/ja/preferences) → **自動保存** をオンにして **間隔**(3〜60分、最初の値は10分)を決めると、その間隔ごとにプロジェクトファイルが保存されます。

## 保存できないとき (失敗版)

ほかのプログラムがファイルを使っている、読み取り専用である、空き容量が足りない、ドライブが外された、といったときは保存に失敗し、理由が表示されます。

- それまでの作業は、アプリ内の **失敗版** に保存しておきます。**失敗版はアプリを閉じると消えます。**
- 残すには、**プロジェクト** → **失敗版をバックアップ** で好きな場所に保存するか、**名前を付けて保存** します。
- 原因がなくなってからもう一度保存すると、元のファイルに保存されます。
- 開いているプロジェクトのファイルが削除されたり移動されたりすると、お知らせします。ごみ箱にあれば、そのときに元に戻してください。

## クラウド・タブレットで

ひとつのファイルはひとつのタブでだけ開きます。ほかのタブで開いているファイルには保存しません。

| | PC<br>(Windows・Mac・Linux) | iPad・iPhone | Android |
|---|---|---|---|
| **ドライブ・Dropbox のファイルを開く** | デスクトップアプリ(Linux は同期ツール)が PC に作ったフォルダーから | ファイルアプリのドライブ・Dropbox・iCloud Drive から — 受信中は「クラウドから受信中 · N秒」 | ファイル画面のドライブ・Dropbox から — **作業用のコピー** で開き、保存のたびにファイル全体をアップロードし直します |
| **フォルダー画面で Google ドライブ** | 選べます(デスクトップアプリのドライブのフォルダー) | **選べません** — 「開く」が押せません。iCloud Drive・Dropbox・この端末を使ってください | **選べません** — 一覧にありません。この端末のフォルダーを使ってください |
| **権限** | 特にありません | 選んだファイル・フォルダーだけ、そのとき許可されます | ファイル・フォルダーを選ぶ前に **すべてのファイルへのアクセス** をオンにする必要があります |

- **フォルダー画面** が出るところ:**フォルダを開く**・読み込み画面の **カットフォルダー**・メディアパネルの **フォルダーから探す**・Android の複数ファイルの書き出し。
- 書き出しをドライブに出すには → [書き出し › Google ドライブに直接書き出す](/ja/export?id=google-ドライブに直接書き出す)
