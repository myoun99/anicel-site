# 再生と録音

## 再生のボタン

タイムライン・コンテパネルの上部の左にあります。

| | ボタン | キー | すること |
|---|---|---|---|
| ![](img/icon-playback-skip-to-start-button.png ':class=icon :no-zoom') | 先頭へ | <span data-k="playback-to-start"></span> | カット(コンテパネルではトラック)の先頭へ |
| ![](img/icon-playback-play-button.png ':class=icon :no-zoom') | 再生 / 停止 | <span data-k="playback-toggle"></span> |  |
| ![](img/icon-playback-loop-toggle.png ':class=icon :no-zoom') | ループ / 1回再生 | <span data-k="playback-loop-toggle"></span> | 終わりから先頭に戻るかどうか |
| ![](img/icon-timeline-camera-view-button.png ':class=icon :no-zoom') | カメラビュー | <span data-k="camera-view-toggle"></span> | カメラフレームの外を隠し、フレームに合わせて再生 → [カンバスの表示](/ja/canvas-view) |
| ![](img/icon-playback-record-voice-button.png ':class=icon :no-zoom') | 録音 | <span data-k="voice-record-toggle"></span> | 下の「録音」 |
|  | 音声レベルメーター |  | いま鳴っている音の大きさ |

- **タイムライン** で再生するといまのカットだけ、**コンテパネル** で再生するとすべてのカットを続けて再生します。
- 再生・先頭へのキーは、最後に触ったパネルのボタンを押します。
- 指では、4本指タップが再生 / 停止です。→ [タッチとペン](/ja/touch-pen)

## 再生方式

絵がまだ用意できていないフレームに来たときにどうするかを、**設定**(⚙) → **プロジェクト設定** → **再生方式** で選びます。

| 方式 | すること |
|---|---|
| **すべてのフレーム**(既定) | 絵が用意できるまで、その手前で少し待ってから続けます。絵を飛ばしません |
| **フレームを飛ばす** | 時間を守り、間に合わなかった絵は飛ばします(音と時間が正確) |
| **再生前にレンダリング** | これから再生する区間を先に全部描いてから始めます |

フレームを飛ばして再生すると、飛ばした絵の数が「{n}コマ落ち」と表示されます。

## 録音

![](img/icon-playback-record-voice-button.png ':class=icon :no-zoom') 再生ボタンの横の **マイク** で、セリフ・効果音を録音します。録音は **再生しながら音を受けること** です — 絵とほかの音を見聞きしながら合わせて録ります。

### 最初の一度だけ

1. [環境設定](/ja/preferences?id=オーディオ) → **オーディオ** → **マイクを許可** をオンにします。オフのままだとマイクを押しても「マイクが許可されていません」が出るだけです。
2. OS がマイクの権限をたずねたら許可します。拒否したときは OS の設定で Anicel のマイクをオンにします。
3. 同じところの **入力** でマイクを選び、話してみて **入力レベル** が動くか確かめます。

### 録音する

1. 録音を置く **SE の行** にいます。ほかの行にいるときは **新しい SE の行** ができて、そこに置かれます。
2. 再生ヘッドを始めたい位置に置きます(再生中でもかまいません — 押した位置から)。
3. **マイク**<span data-k="voice-record-toggle" data-k-paren></span>を押します → その位置から再生しながら録音します。録音中はブロックと波形が伸びていくのが見えます。
4. **マイク** をもう一度押すか **停止** すると止まり、そのテイクが SE の行にブロックとして置かれます。

| 知っておくこと | |
|---|---|
| 聞こえる音 | ほかの行の音はそのまま聞こえ、**録音中の行** の音だけ消えます |
| すでにブロックがある位置 | 新しいテイクがその区間を取ります — 重なった部分だけ切られ、元の音のファイルはメディアパネルに残ります |
| 元に戻す | 取り消し一回で、テイクと切られたブロックがすべて戻ります |
| テイクのある場所 | プロジェクトファイルの中・メディアパネル |
| 音が大きすぎたとき | 一度でも割れるとマイクの右上に **赤い点** がつきます。**クリッピング警告** をオンにしておくと、お知らせとブロックの赤い角も |

### 決めた区間だけ録音する (パンチイン)

SE の行で録音したい区間を **範囲で選び**、それより前に再生ヘッドを置いてマイクを押します。再生は再生ヘッドから回りますが、録音は **範囲の中だけ** です — 前の部分を聞きながら入るタイミングをつかみます。

| 合図 (環境設定 → オーディオ) | 最初 | すること |
|---|---|---|
| **キュービープ** | オン | 範囲の始まりの前に1秒おきに「ピッ・ピッ・ピッ」 — 3回目のすぐあとが始まり |
| **ストリーマー** | オン | 始まる前の最大3秒、画面を横切って帯が進み、端に届いた瞬間が始まり |

### すぐに始めないとき (カウントイン)

**カウントイン**(最初は0秒 = オフ)に秒数を決めておくと、マイクを押してからその分待って再生が始まります(キュービープがオンなら待つあいだピッと鳴ります)。範囲を選んだ録音では使われません。

### 音を整える設定 (環境設定 → オーディオ)

| 設定 | 最初 | |
|---|---|---|
| **マイクゲイン** | 0 dB | 受ける音の大きさ |
| **入力チャンネル** | 装置のまま | モノラルミックス / 左のみ / 右のみ |
| **ノイズ抑制** | オフ | 声用 — 足音・小道具の音まで消すので、効果音を録音するときはオフにします |
| **クリッピング警告** | オフ | 割れたテイクをお知らせ + ブロックの角を赤く |

ゲイン・入力チャンネルは、録音を始めたときの値でひとつのテイクを最後まで録ります。録音中に変えると次のテイクからです。

## 音と絵がずれるとき

- **A/Vオフセット**(環境設定 → オーディオ):絵を音より何フレーム遅く・早く表示するかを微調整します。ワイヤレスイヤホンは音が 150〜300ms 遅れて鳴ることがよくあるので、イヤホンで聞いていてずれるときはここで合わせます。
- **出力**・**入力**:使うスピーカーとマイクを選びます。
- 音が鳴らないブロックは、再生中に「音声n件 再生不可」と知らせます(ファイルがない、まだダウンロード中、読めない形式のいずれか)。
