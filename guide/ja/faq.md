# よくある質問

## 保存・ファイル

**アプリが落ちて、作業がなくなりました。**
自動保存は最初はオフになっています。[環境設定](/ja/preferences) → **自動保存** をオンにしておくと、決めた間隔ごとに保存されます。→ [開く・保存](/ja/files?id=自動保存)

**保存に失敗したと表示されます。**
それまでの作業は、アプリ内の **失敗版** にあります。アプリを閉じる前に、**プロジェクト** → **失敗版をバックアップ** か **名前を付けて保存** で、別の場所に残してください。→ [開く・保存](/ja/files?id=保存できないとき-失敗版)

**別の機器で開いたら、絵・音・映像の一部がありません。**
「リンク」で取り込んだファイルは、元のファイルがプロジェクトファイルの外にあります。メディアパネルの **フォルダーから探す** でつなぎ直すか、移す前に **プロジェクトファイルに取り込む** をしておいてください。→ [メディアパネルとインポート](/ja/media-pool?id=リンクしたファイルが見つからないとき)

**Google ドライブ・Dropbox のファイルを直接開けますか？**
はい。**ファイルを開く** の画面で、ドライブ・Dropbox にあるプロジェクトファイルを選べば開けます。フォルダーを選ぶ画面では機器によってドライブを選べず、書き出しも機器とファイルの数で変わります — 表は[開く・保存 › クラウド・タブレットで](/ja/files?id=クラウド・タブレットで)と[書き出し › Google ドライブに直接書き出す](/ja/export?id=google-ドライブに直接書き出す)にあります。

**TVPaint・CLIP STUDIO のファイルを開けますか？**
`.tvpp`・`.clip` を **ファイルを開く** で開くと、新しいプロジェクトとして入ります。元のファイルは変わりません。→ [開く・保存](/ja/files)

## 描く

**描けません。**
- いまのレイヤーが絵を受け付けるレイヤーか確かめてください。フォルダー・調整レイヤー・SE・カメラの行、それにファイルのまま置かれた **参照の画像レイヤー** には描けません(参照の画像は **ラスタライズ** すると描けます)。→ [レイヤーの概要](/ja/layers)
- 空きコマなら、**✦**(フレーム自動生成)をオンにするか、**フレーム ＋** で先に絵を作ってください。

**筆圧が効きません(Windows)。**
[環境設定](/ja/preferences) → **入力** → **タブレットサービス** を **標準** ↔ **Wintab** で切り替えてみてください。

**ペンのサイドボタンを押すとスポイトになります。**
既定の動作です。[環境設定](/ja/preferences) → **入力** → **カンバス** で変えます。→ [タッチとペン](/ja/touch-pen)

**前の絵が透けて見えません。**
オニオンスキンは **レイヤーごと** にオンにします。そのレイヤーの行のオニオンスキンの欄か、**オニオンスキンの切り替え**<span data-k="onion-skin-toggle" data-k-paren></span>。→ [オニオンスキン](/ja/onion-skin)

**レイヤーのロック・ライトテーブル・テキストレイヤーはどこですか？**
レイヤーのロックはありません。透かして見るのは[オニオンスキン](/ja/onion-skin)で、文字は[テキストツール](/ja/tools?id=テキスト)で絵の中に入れます。

## 画面

**パネルが消えました / 配置がぐちゃぐちゃになりました。**
**設定**(⚙) → **パネル** でパネルをもう一度オンにするか、**ワークスペース配置をリセット** を押してください。→ [画面とパネル](/ja/screen)

**画面の言語を変えたいです。**
[環境設定](/ja/preferences) → **言語** → **プログラム言語**。タイムシートに記入される言語は、**表記言語** で別に決めます。

**使っていたアプリとショートカットをそろえたいです。**
**設定** → **キーボードショートカット** で **CLIP STUDIO ベース**・**TVPaint ベース** のプリセットを選ぶか、そのアプリのショートカットファイルを読み込んでください。→ [ショートカット](/ja/shortcuts)

## 再生・音

**再生がところどころ止まります。**
既定の再生方式(**すべてのフレーム**)は、絵が用意できるまで待ちます。時間を守って再生するなら **フレームを飛ばす**、先に全部描いておくなら **再生前にレンダリング**。→ [再生と録音](/ja/playback?id=再生方式)

**音が出ません。**
[環境設定](/ja/preferences) → **オーディオ** の **出力** デバイスを確かめてください。再生中に「音声n件 再生不可」と出たら、その音のファイルがないか、まだダウンロード中か、読めない形式です。

**ワイヤレスイヤホンで聞くと、音と絵がずれます。**
**A/Vオフセット** で合わせます。→ [再生と録音](/ja/playback?id=音と絵がずれるとき)

**録音できません。**
[環境設定](/ja/preferences) → **オーディオ** → **マイクを許可** をオンにし、OS の設定で Anicel のマイクの権限も許可してください。

## 書き出し

**動画の形式の一部が灰色です。**
この機器の OS がそのコーデックに対応していない場合です。このパソコンの PATH に **FFmpeg** があれば、それで出せます。→ [書き出し](/ja/export)

**書き出した動画に音がありません。**
連番タブの **音声** で **SEミックスを動画に多重化** をオンにしてください。ミュートした SE の行は除かれます。
