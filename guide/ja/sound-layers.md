# サウンドレイヤー

音を SE の行に置き、波形を見ながら絵とタイミングを合わせます。

![](img/sound.png)

- 左上の **プロジェクト**(フォルダ) → **ファイルを開く…** で音のファイルを選ぶと、**インポート** 画面で SE の行に置かれます。
- 波形は SE のブロックの上にいつも薄く見えます。行の左の **▸** で開くと、**音声** レーンで音をブロックの中でずらしたり、端をドラッグしてフェードをかけたりします。
- 再生ボタンの隣のマイクボタンで、再生ヘッドの位置に声を録音します。
- SE のブロックの名前・セリフは[編集ボタン](/ja/timeline?id=編集ボタン)で入れ、[タイムシート・コンテ用紙](/ja/sheets)にそのまま記入されます。
- 名前はカンバスにネームタグとしても見えます。ネームタグはカメラフレームの中の位置を保ち、SE の行の **ネームタグ** レーン(サイズ・字間・太字など)と **トランスフォーム**・合成モード・エフェクトを、レイヤーと同じように受けます。
