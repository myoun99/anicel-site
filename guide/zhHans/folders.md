# 文件夹

![](img/folder.png ':size=1188')

把多个图层编成组，一起显示、隐藏，并一起设置不透明度、混合、效果和变换。

## 新建并放入图层

- 用 **图层 ＋ ▾ → 文件夹** 新建一个空文件夹（名为 **Folder 1** …）。
- 拖动图层行放到文件夹行上，它就会进入 **那个文件夹里**。拖出文件夹就会移出。
- 文件夹里可以再放文件夹。
- 用名称末尾的折叠按钮折叠和展开文件夹。

## 文件夹行的作用

| 格子 | 作用 |
|---|---|
| 眼睛 | 一次隐藏 / 显示里面的所有图层 |
| 不透明度 | 整个文件夹的不透明度 |
| 混合 | 见下面的“穿透与其他混合模式” |
| 剪贴 | 把整个文件夹剪贴到下一图层 |
| FX · 参数轨 | 对整个文件夹的 [效果与变换](/zhHans/effects) |

- 不能在文件夹里画画（文件夹没有单元格）。
- 用变换工具选中文件夹，里面的所有图层会一起移动。
- 文件夹不能复制粘贴。

## 穿透与其他混合模式

- **穿透**（默认）：就像没有文件夹一样，里面的每个图层各自与下面的画面混合。里面的 [调整图层](/zhHans/adjustment-layers) 也会影响文件夹外面、下面的图层。
- **正常 · 正片叠底 …**（穿透以外的模式）：文件夹里面先合成一张图，再以所选方式与下面混合。里面的调整图层只影响文件夹内部。
