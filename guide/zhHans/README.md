# Anicel

用于制作手绘动画的应用。一个项目就是一个文件。
同一个文件可以在 Windows、macOS、iPad、Android 和 Linux 上打开。

[](../../launch/latest/zhHans/notice.md ':include')

从分镜到摄影，同一个镜头可以在一个项目文件中连续完成。不过在当前版本中，**动画、上色和摄影**的功能还不足以完全取代专用软件，功能会随着每次更新不断增加。如果您有想要的功能或任何意见，请通过[**发送反馈**](/zhHans/feedback)（⚙ 设置菜单）告诉我们，我们会认真考虑。

- 一个项目里放多个镜头，每个镜头有自己的画布尺寸 — [各镜头的画布尺寸](/zhHans/canvas-size)
- 图层：动画、分镜、图像、文件夹、调整、SE、Direction、Camera、Transition，以及附在主图层上的附属图层 — [图层一览](/zhHans/layers)
- 给图层和镜头加上颜色标签和 Take — [颜色标签与 Take](/zhHans/layer-labels)
- 一边工作一边查看摄影表、分镜用纸和卡袋，并导出它们 — [摄影表 · 分镜用纸 · 卡袋](/zhHans/sheets)
- 把声音文件放到 SE 图层上，也可以用麦克风录音 — [声音（SE）图层](/zhHans/sound-layers) · [播放与录音](/zhHans/playback)
- 导入 CLIP STUDIO（.sut）和 Photoshop（.abr）画笔 — [画笔](/zhHans/brushes)
- 把 TVPaint（.tvpp）和 CLIP STUDIO（.clip）文件作为项目打开 — [打开与保存](/zhHans/files)
- 导出视频（MP4、MOV）、序列图、赛璐珞、摄影表和分镜用纸（PDF） — [导出](/zhHans/export)
