# 画笔

## 选择画笔

![](img/tool-brush-library.png ':size=328')

选择画笔工具 <span data-k="tool-brush" data-k-paren></span> 或橡皮 <span data-k="tool-eraser" data-k-paren></span>，画笔列表会出现在 **工具库** 里。

- 左边是 **分组** 标签，旁边是该组的画笔。点一下就切换到那支画笔。
- 内置分组：基础 · 铅笔 · 笔 · 干性画材 · 水彩 · 油画 · 喷枪 · 混色 · 纹理 · 装饰。
- 拖动画笔可以改变顺序。拖到另一个分组的标签上停一会儿：那个分组会打开，可以把画笔移过去。
- 每个分组和每支画笔都可以设快捷键（画笔工具和橡皮分开设）。→ [快捷键](/zhHans/shortcuts)

## 大小与不透明度

在画布的 **左边缘竖向胶囊** 上调整。

- 顶部的小块：**混合模式**（正常 · 背后 · 擦除 · 变暗 · 正片叠底 …）。
- **大小**（0.1–2000 px）和 **不透明度** 滑条：拖动来改变。± 和鼠标滚轮会按 [工具大小](/zhHans/brushes?id=工具大小) 的档位一档一档地变。
- 按数字旁边的 **铅笔按钮**（输入数值），会打开数字键盘。按下的第一个键会替换原来的值；用 ✓ 或 <kbd class="k-pc">Enter</kbd><kbd class="k-mac">↩</kbd> 确定，用 <kbd class="k-pc">Esc</kbd><kbd class="k-mac">⎋</kbd> 退出。
- 滑条下面的曲线按钮用来设置该数值的 **响应**（笔压 · 倾斜 · 速度 · 随机，最小值 · 最大值）。
- 要把胶囊移到顶部栏，用 **设置**（⚙）→ **面板** → **画笔数值放在顶部栏**。

### 工具大小

![](img/panel-tool-size.png ':size=328')

右侧栏的 **工具大小** 面板里放着 40 个常用的大小（0.7–2000）。点一下就用那个大小。拖动大小滑条时，也会吸附到这些数值上。

## 画笔设置

![](img/tool-brush-settings.png ':size=328')

**工具设置** 面板里有当前画笔的所有数值。改变数值时，顶部的预览笔画也会跟着变。与这支画笔无关的项目会隐藏。

| 分组 | 主要项目 |
|---|---|
| **墨水** | 流量（+笔压） |
| **笔尖** | 笔尖形状（可以从图像添加笔尖） · 重复方法 · 硬度 · 抗锯齿 · 圆度 · 角度（线条方向 · 笔的方向 · 笔杆旋转 · 随机） · 间距 |
| **混色** | 与底色混合 / 模糊 · 颜料量 · 颜料浓度 · 色彩延伸 |
| **散布** | 散布 % · 数量（1–16） · 双轴 |
| **纹理** | 双重笔尖（缩放 · 浓度 · 混合） · 纹理（缩放 · 浓度 · 正片叠底/高度 · Invert · Brightness · Contrast） |
| **修正** | 锐化拐角 · 防抖（0–100，按速度） · 后修正（0–100，按速度和缩放调整） · 贝塞尔曲线 |

每支画笔都会记住你改过的数值，导出画笔时这些数值也会一起带走。

## 制作自己的画笔

- 列表顶部的 **＋**（将当前设置保存为预设）— 把当前的数值保存为一支新画笔。
- **⋯** 菜单：新建分组 · 重命名分组 · 删除分组 · 重命名所选画笔 · 删除 · 导出画笔 · 导出画笔组 · 重置画笔库。显示方式（笔尖图标 · 笔画预览 · 名称）也在这里切换。
- 在 [裁剪工具](/zhHans/tools?id=裁剪) 的图章里用 **注册为笔尖**，手里拿着的画就会变成画笔笔尖。

## 导入其他应用的画笔

用 **导入画笔** 按钮选文件，或者把文件拖到窗口上。

| 格式 | 应用 |
|---|---|
| `.abr` | Photoshop（版本 6 · 7 · 10。很旧的 1 和 2 无法读取） |
| `.sut` · `.sutg` | CLIP STUDIO PAINT |
| `.anibrush` | Anicel（导出的画笔） |

## 笔压

- 每支画笔的响应用上面的曲线按钮设置；**整个应用的笔压曲线** 在 [偏好设置](/zhHans/preferences) → **输入** → **压感曲线** 里设置。
- 如果在 Windows 上笔压不正常，可以在同一个地方切换 Windows 的 **数位板服务**（标准 / Wintab）试试。
