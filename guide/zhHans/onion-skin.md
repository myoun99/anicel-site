# 洋葱皮

一边画，一边把前后的画稿淡淡地叠在当前画稿上看。洋葱皮是 **按图层** 打开的（没有全局开关）。

| 位置 | |
|---|---|
| ![](img/icon-rail-onion-skin-button.png ':class=icon :no-zoom') 工具条顶部 | 当前图层<span data-k="onion-skin-toggle" data-k-paren></span> |
| 图层行上的 **洋葱皮** 格子 | 该图层。按住后上下划过，可以一次设置多行 |
| 轨道头表头行的洋葱皮格子 | **对显示的图层应用洋葱皮 / 清除显示图层的洋葱皮** |

可用于动画、分镜和 Direction 图层。

## 洋葱皮面板

| | |
|---|---|
| ![](img/icon-rail-group-rail-R4.png ':class=icon :no-zoom') | 右侧栏上的按钮（与工具大小共用）。这里的设置是应用设置，所有项目都一样 |

![](img/panel-onion-skin.png ':class=panel')

- 中间的 ● 是当前画稿；左边 8 个是 **之前** 的，右边 8 个是 **之后** 的。
- **滑条的高度 = 浓度**。上下拖动来调整（初始值：之前 40%，之后 30%）。
- 点滑条下面的数字，只关掉那一个；再点一次恢复它的浓度。

| 顶部的按钮 | 选择的内容 |
|---|---|
| **Blocks** / **Frames** | 一格算一张画稿还是一帧 |
| **Colors** / **Images** | 残影用设定的颜色 / 用画稿本身的颜色 |
| **In place**（默认） / **On top** | 紧贴在各图层画稿的下面（会被上面的图层遮住，跟随该图层的混合、文件夹和剪贴） / 在所有图层的上面 |
| 红 · 绿圆圈 | 选 Colors 时，之前和之后画稿的颜色 |

## 想透看别的图层时

洋葱皮显示的是该图层自己的前后画稿。要把别的图层的画稿当作底稿，请让那个图层保持显示，并降低它的 **不透明度**。
