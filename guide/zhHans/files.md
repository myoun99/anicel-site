# 打开与保存

在左上角的 **项目**（文件夹图标）菜单里操作。

## 项目文件

- 一个 Anicel 项目就是 **一个 `.anicel` 文件**。画稿、摄影表、声音和设置全都在里面（以“链接”方式导入的声音和视频仍然需要原文件 → [媒体面板与导入](/zhHans/media-pool)）。
- 打开多个项目时，它们会作为标签页并排在顶部栏上。

## 打开

![](img/menu-project.png ':size=245')

**项目** → **打开文件**（或把文件拖到窗口上）。打开到哪里取决于打开的是什么。

| 文件 | 打开到 |
|---|---|
| `.anicel` · `.tvpp`（TVPaint） · `.clip`（CLIP STUDIO PAINT） | 新的项目标签页 |
| 图片 · 视频 · 声音 · PDF | [导入窗口](/zhHans/media-pool) |
| `.abr` · `.sut` · `.sutg` · `.anibrush` | [画笔](/zhHans/brushes) 库 |
| `.ttf` · `.otf` · `.ttc` | 字体（[文字工具](/zhHans/tools)） |
| 其他应用的快捷键文件 | [快捷键](/zhHans/shortcuts) 预设 |

- **打开文件夹**：在导入窗口里打开整个镜头文件夹（放着图片文件的文件夹）。
- **最近的项目**：最近打开过的文件。文件被移动而找不到时，用 **重新连接** 告诉应用它的新位置。
- 把文件拖到 [查看器](/zhHans/screen) 上，会在那个查看器里显示，而不是作为项目打开。

### TVPaint 和 CLIP STUDIO 文件

- 打开 `.tvpp`，它的图层、时间和中间画标记会变成 Anicel 的图层、块和标记。
- 打开 `.clip`，它的动画赛璐珞会作为图层和块导入，赛璐珞里的图层会作为 [附属图层](/zhHans/attach-layers)（A · A-1 …）导入。
- 原文件不会改变。保存时保存为 `.anicel`。

## 保存

| 菜单 | 按键 | 内容 |
|---|---|---|
| 保存 | <span data-k="file-save"></span> | 只有第一次会询问位置和名称 |
| 另存为 → 项目(.anicel) | <span data-k="file-save-as"></span> | 存为另一个文件 |
| 另存为 → PNG · JPG · BMP · TGA · TIFF … | | 把 **当前这一帧** 存为画布大小的图片 |

导出多张图片、视频或赛璐珞，请看 [导出](/zhHans/export)。

## 自动保存

**自动保存一开始是关闭的。** 关闭时，项目只在你保存时改变；如果应用意外退出，上次保存之后的工作会丢失。

- 打开 [偏好设置](/zhHans/preferences) → **自动保存** 并设定间隔（**间隔**：3–60 分钟，初始 10 分钟），项目文件就会按这个间隔保存。

## 保存失败时（失败副本）

当其他程序正在使用该文件、文件是只读的、空间不足或驱动器被拔出时，保存会失败，并显示原因。

- 到那时为止的工作会保存在应用内的 **失败副本** 里。**关闭应用后失败副本会消失。**
- 要保留它，用 **项目** → **备份失败副本** 保存到想要的位置，或者用 **另存为**。
- 原因消除后再保存一次，就会保存到原文件。
- 如果打开中的项目文件被删除或移动，应用会通知你。如果在回收站里，请到那时再恢复。

## 云存储与平板

一个文件只能在一个标签页里打开。不会覆盖保存另一个标签页中打开着的文件。

| | 电脑<br>（Windows · Mac · Linux） | iPad · iPhone | Android |
|---|---|---|---|
| **打开 Drive 或 Dropbox 里的文件** | 从桌面应用（Linux 上是同步工具）在电脑上建立的文件夹打开 | 从“文件”应用里的 Drive · Dropbox · iCloud Drive 打开 — 下载期间显示“Downloading from the cloud · Ns” | 从文件窗口里的 Drive · Dropbox 打开 — 会作为 **工作副本** 打开，每次保存都会重新上传整个文件 |
| **在文件夹窗口里选 Google Drive** | 可以选（桌面应用的 Drive 文件夹） | **不能选** — 打开没有反应。请用 iCloud Drive、Dropbox 或本机 | **不能选** — 不在列表里。请用本机上的文件夹 |
| **权限** | 不需要 | 只有选中的那个文件或文件夹，在选的那一刻 | 选任何文件或文件夹之前，都必须先打开 **所有文件访问权限** |

- 会打开 **文件夹窗口** 的地方：**打开文件夹** · 导入窗口里的 **镜头文件夹** · 媒体面板里的 **在文件夹中查找** · 在 Android 上导出多个文件时。
- 导出到 Drive → [导出 › 直接导出到 Google Drive](/zhHans/export?id=直接导出到-google-drive)
