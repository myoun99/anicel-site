# 触摸与笔

以下全部在 [偏好设置](/zhHans/preferences) → **输入** 里更改。

![](img/prefs-input.png ':size=720')

## 手指（在画布上）

| 手指 | 默认 | 可选 |
|---|---|---|
| 单指拖动 | **翻页** — 左右是上一张、下一张画稿，上下是上面、下面的图层 | 翻页（帧 / 图层） · 画面（平移·缩放·旋转） · 笔刷大小 · 触摸绘制 · 无 |
| 双指 | **画面** — 平移 · 缩放 · 旋转 | |
| 三指 | **笔刷大小** — 上下拖动 | |

- 拖动中 **再放下一根手指**，操作会变细一档：翻页一次移动一个单元格，画面的缩放和旋转按档位吸附，笔刷大小吸附到 [工具大小](/zhHans/brushes?id=工具大小)（**加指修饰键**，默认开启）。
- **触摸绘制** 只能分配给单指。在没有笔的设备上用手指画画时使用。
- 打开 **忽略所有触摸** 后，画布不再响应手指（只响应笔）。

### 点按

| 点按 | 动作 |
|---|---|
| 双指点按 | 撤销 |
| 三指点按 | 重做 |
| 四指点按 | 播放 / 停止 |

双指或三指的 **长按** 可以分配任意动作。

### 其他项目

| 项目 | 内容 |
|---|---|
| 翻页震动 | 每次翻页落到另一张画稿上时短促震动一下（只在有振动马达的设备上） |
| 双指旋转 | 关闭时，双指只做平移和缩放（旋转按钮和按键仍然有效） |
| 修饰键锁定旋转 | 开启时，多放的手指会锁住角度（平移 + 按档缩放）。关闭时（默认），角度按档位吸附 |
| 旋转吸附 · 缩放吸附 | 各档位的数值 |
| 锁定最大缩放 | 不会放大超过这个值（适应窗口也停在这里） |

## 用手指代替按键

在没有键盘的平板上用笔工作时，**放在屏幕任意位置的另一根手指** 可以代替 <kbd class="k-pc">Shift</kbd><kbd class="k-mac">⇧</kbd> 和 <kbd class="k-pc">Alt</kbd><kbd class="k-mac">⌥</kbd>。

- 用笔拖动时放下一根手指，就相当于 <kbd class="k-pc">Shift</kbd><kbd class="k-mac">⇧</kbd> — 移动只沿一个方向，形状的锁定比例会切换。要把笔画拉直到 45°，请打开 **手指笔画修饰键**（默认关闭）。
- 拖动变换框的角时放下一根手指，就相当于 <kbd class="k-pc">Alt</kbd><kbd class="k-mac">⌥</kbd> — 以对角为基准改变大小。

## 笔和鼠标按键

| 按键 | 默认 | 可选 |
|---|---|---|
| 右键 / 笔侧键 | 吸管 | 吸管 · 橡皮 · 抓手 · 撤销 · 重做 · 无 |
| 滚轮点击 / 笔上键 | 无 | 〃 |
| 笔尾（把笔倒过来） | 橡皮 | 〃 |

- 选择松开按键后是回到原来的工具（**返回原工具**），还是留在那个工具上（**保持**）。
- Apple Pencil 的双击（画笔 ⇄ 橡皮）按 iPad 的系统设置执行。

## 笔压

- **压感曲线**：整个应用的笔压响应。每支画笔自己的响应见 [画笔](/zhHans/brushes?id=大小与不透明度)。
- **数位板服务**：标准 / Wintab。如果笔压不起作用或不正常，试着切换一下。
