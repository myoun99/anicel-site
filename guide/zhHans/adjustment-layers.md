# 调整图层

![](img/adjustment-layer.png ':size=1188')

对 **它下面的所有图层** 加效果（亮度 · 色相 · 模糊 …）的图层。它本身不含画稿。

## 用法

1. 用 **图层 ＋ ▾ → 调整图层** 新建（名为 **FX1** …）。新建的调整图层还没有任何效果。
2. 用 **▸** 展开这一行，添加效果。可以添加的效果和数值与 [效果与变换](/zhHans/effects) 相同。
3. 把这一行移到想影响的图层的 **上面**。它上面的图层不受影响。

## 须知

- **不透明度** 就是效果的强度（0% = 无效果，100% = 完全）。
- 没有混合和变换。
- 在文件夹里：如果文件夹是 **穿透**，效果也会作用到文件夹下面；其他混合模式时，只作用于 **文件夹内部**。→ [文件夹](/zhHans/folders)
- 效果可以用关键帧随时间变化（每条参数轨上的关键帧）。
- 调整图层不能复制粘贴。
- 即使转换为 [链接镜头](/zhHans/linked-cuts)，调整图层在各个镜头中仍然是分开的。
