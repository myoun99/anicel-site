# 播放与录音

## 播放按钮

位于时间轴和分镜面板的左上方。

| | 按钮 | 按键 | 作用 |
|---|---|---|---|
| ![](img/icon-playback-skip-to-start-button.png ':class=icon :no-zoom') | 回到开头 | <span data-k="playback-to-start"></span> | 回到镜头的开头（在分镜面板上则是轨道的开头） |
| ![](img/icon-playback-play-button.png ':class=icon :no-zoom') | 播放 / 暂停 | <span data-k="playback-toggle"></span> |  |
| ![](img/icon-playback-loop-toggle.png ':class=icon :no-zoom') | 循环 / 单次播放 | <span data-k="playback-loop-toggle"></span> | 播到结尾时是否回到开头 |
| ![](img/icon-timeline-camera-view-button.png ':class=icon :no-zoom') | 摄像机视图 | <span data-k="camera-view-toggle"></span> | 遮住摄像机框以外的部分，并按框的大小播放 → [画布视图](/zhHans/canvas-view) |
| ![](img/icon-playback-record-voice-button.png ':class=icon :no-zoom') | 录音 | <span data-k="voice-record-toggle"></span> | 见下面的“录音” |
|  | 音频电平表 |  | 当前播放的声音有多大 |

- 在 **时间轴** 上播放只播当前镜头；在 **分镜面板** 上播放则连续播放所有镜头。
- 播放键和回到开头键作用于你最后触碰的那个面板的按钮。
- 用手指时，四指点按是播放 / 停止。→ [触摸与笔](/zhHans/touch-pen)

## 播放方式

在 **设置**（⚙）→ **项目设置** → **播放方式** 里，选择播放到画稿还没准备好的帧时怎么办。

| 方式 | 作用 |
|---|---|
| **所有帧**（默认） | 在那一帧前稍等，画稿准备好后再继续。绝不跳过画稿 |
| **跳帧** | 保持时间，跳过来不及画出的画稿（声音和时间保持准确） |
| **播放前渲染** | 先把要播放的整段画出来，然后开始播放 |

用跳帧播放时，跳过的画稿数会显示为“跳过{n}帧”。

## 录音

![](img/icon-playback-record-voice-button.png ':class=icon :no-zoom') 用播放按钮旁边的 **麦克风** 录台词和音效。录音就是 **一边播放一边收音** — 一边看画面、听其他声音，一边对着录。

### 第一次的准备

1. 打开 [偏好设置](/zhHans/preferences?id=音频) → **音频** → **允许麦克风**。关闭时，麦克风只会提示未允许使用麦克风。
2. 系统询问麦克风权限时，选择允许。如果拒绝过，请在系统设置里打开 Anicel 的麦克风权限。
3. 在同一个地方的 **输入** 下选择麦克风，说话看看 **输入电平** 有没有动。

### 录一条

1. 停在录音要放进去的 **SE 行** 上。停在其他行上时，会新建一个 **SE 行** 并放到那里。
2. 把播放头放到要开始的位置（正在播放也可以 — 从按下的位置开始）。
3. 按 **麦克风** <span data-k="voice-record-toggle" data-k-paren></span> → 从那里一边播放一边录音。块和它的波形会随着录音变长。
4. 再按一次 **麦克风** 或 **停止**，录下的内容会作为块放到 SE 行上。

| 须知 | |
|---|---|
| 听到的声音 | 其他行照常播放；只有 **正在录音的那一行** 静音 |
| 已经有块的地方 | 新录的内容优先占用那一段 — 只切掉重叠的部分，原来的声音文件仍留在媒体面板里 |
| 撤销 | 一次撤销就能还原这条录音和被它切掉的块 |
| 录音保存在哪里 | 项目文件内 · 媒体面板里 |
| 声音过大 | 哪怕只削波一次，麦克风右上角也会亮起 **红点**。打开 **削波警告** 时，还会有提示和块的红角 |

### 只录一段（切入录音）

在 SE 行上 **选中要录的范围**，把播放头放在它前面，按麦克风。播放从播放头开始，但 **只在范围内录音** — 可以听着前面的部分，抓准开口的时机。

| 信号（偏好设置 → 音频） | 初始 | 作用 |
|---|---|---|
| **提示音** | 开 | 在范围之前每隔一秒响一声，共三声 — 第三声之后立刻开始 |
| **光带** | 开 | 开始前最多 3 秒，一条光带横穿画面；光带到达边缘的那一刻开始 |

### 不立刻开始（倒数）

设好 **倒数**（初始为 0 秒 = 关），按麦克风后，播放会等待这么长时间再开始（打开提示音时，等待中会响提示音）。选了范围的录音不使用倒数。

### 影响声音的设置（偏好设置 → 音频）

| 设置 | 初始 | |
|---|---|---|
| **麦克风增益** | 0 dB | 输入声音的大小 |
| **输入声道** | 按设备 | 单声道混合 / 仅左声道 / 仅右声道 |
| **降噪** | 关 | 用于人声 — 脚步声和道具声也会被去掉，所以录音效时请关闭 |
| **削波警告** | 关 | 对削波的录音给出提示，并在块上标红角 |

增益和输入声道从录音开始到结束都保持开始时的设置。录音中修改的话，从下一条开始生效。

## 声音和画面错开时

- **A/V 偏移**（偏好设置 → 音频）：微调画面比声音晚或早几帧显示。无线耳机播放声音常常晚 150–300 ms，所以戴耳机听时如果对不上，在这里调整。
- **输出** · **输入**：选择要用的扬声器和麦克风。
- 播放中发不出声音的块会报告为“{n}个音频无法播放”（文件丢失、还在下载中，或格式无法读取）。
