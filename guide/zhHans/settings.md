# 项目设置

**设置**（⚙）菜单最上面的两行 **只作用于这个项目**（保存在文件里）。作用于整个应用的设置在 [偏好设置](/zhHans/preferences) 里。

## 作品设置

![](img/work-settings.png ':size=460')

- 标题和集数会印在摄影表、分镜用纸和卡袋的表头上。
- **封面图** 从 [媒体面板](/zhHans/media-pool) 里的图片中选择。
- **人员设置**：每道工序的负责人。如果每个镜头不同，在 **镜头** 胶囊 → **镜头设置** 里设定。

## 项目设置

![](img/menu-project-settings.png ':size=496')

每一行显示当前的值；点一下会打开修改它的窗口。

| 行 | |
|---|---|
| **FPS** | 在有声音的项目里，像 23.976 ↔ 24 这样修改时，会询问声音怎么办：**保持音频时间** / **拉伸音频 0.1%** |
| **项目音频采样率** | 44.1 · 48 · 96 kHz |
| **摄影机** | 摄像机框的大小（整个项目共用）。也可以用 **在画布上调整** 在画布上拖动。画布（画画用的纸）每个镜头有自己的尺寸 → [各镜头的画布尺寸](/zhHans/canvas-size) |
| **播放方式** | 遇到画稿还没准备好的帧时：**所有帧**（默认） · **跳帧** · **播放前渲染** → [播放与录音](/zhHans/playback) |
