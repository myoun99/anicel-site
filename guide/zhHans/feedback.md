# 发送反馈

问题、想要的功能、使用中的感受，都可以直接从应用里发送。

## 发送方法

1. 在 **设置**（⚙）菜单的最下面，**关于 Anicel** 的下方，点 **发送反馈**。
2. 在窗口中二选一。

| 按钮 | |
|---|---|
| **仅文字** | 只发送文字，无需登录。 |
| **附截图 / 视频（需登录 Google）** | 附上截图、录屏等图片和视频，需要登录 Google。 |

3. 浏览器中会打开 Google 表单，**设备、系统、系统版本和应用版本号** 已预先填好。写好内容后提交。

- 表单是英文的。
- 只能附加图片和视频。
- 不会填入电脑名称、用户名等其他设备信息。

## 打不开旧文件时

如果新版本打不开您以前的文件，请将该文件上传到 GigaFile 等文件传输网站，然后在 **发送反馈** 中填写 **下载链接** 和 **接收转换后文件的电子邮箱**。我们会将其转换为新格式后发送给您。
