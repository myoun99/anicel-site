# 常见问题

[](../../launch/latest/zhHans/notice.md ':include')

## 保存与文件

**应用关掉了，作品不见了。**
自动保存一开始是关闭的。打开 [偏好设置](/zhHans/preferences) → **自动保存**，就会按你设的间隔保存。→ [打开与保存](/zhHans/files?id=自动保存)

**提示保存失败。**
到那时为止的工作保存在应用内的 **失败副本** 里。在关闭应用之前，用 **项目** → **备份失败副本** 或 **另存为** 把它保存到别处。→ [打开与保存](/zhHans/files?id=保存失败时（失败副本）)

**在另一台设备上打开项目，部分图片、声音或视频不见了。**
以“链接”方式导入的文件，原文件在项目文件外面。在媒体面板里用 **在文件夹中查找** 重新链接，或者在移动项目之前用 **收入项目文件**。→ [媒体面板与导入](/zhHans/media-pool?id=链接的文件找不到时)

**能直接打开 Google Drive 或 Dropbox 上的文件吗？**
可以。在 **打开文件** 窗口里选择 Drive 或 Dropbox 上的项目文件就能打开。文件夹窗口能否选 Drive、导出能否直达，取决于设备和文件数量 — 表格见 [打开与保存 › 云存储与平板](/zhHans/files?id=云存储与平板) 和 [导出 › 直接导出到 Google Drive](/zhHans/export?id=直接导出到-google-drive)。

**能打开 TVPaint 和 CLIP STUDIO 的文件吗？**
用 **打开文件** 打开 `.tvpp` 或 `.clip`，会作为新项目导入。原文件不会改变。→ [打开与保存](/zhHans/files)

## 绘画

**画不上去。**
- 确认当前图层是可以画画的图层。文件夹、调整图层、SE 和 Camera 行，以及以文件原样保存的 **链接图像图层** 上都不能画（用 **栅格化** 把链接图像栅格化后就能画）。→ [图层一览](/zhHans/layers)
- 如果单元格是空的，打开 **✦**（自动创建帧），或先用 **帧 ＋** 新建画稿。

**笔压不起作用（Windows）。**
在 [偏好设置](/zhHans/preferences) → **输入** → **数位板服务** 里，试着在 **标准** 和 **Wintab** 之间切换。

**按笔的侧键就变成了吸管。**
这是默认设置。在 [偏好设置](/zhHans/preferences) → **输入** → **画布** 里更改。→ [触摸与笔](/zhHans/touch-pen)

**透看不到上一张画稿。**
洋葱皮是 **按图层** 打开的。用该图层行上的洋葱皮格子，或 **切换洋葱皮** <span data-k="onion-skin-toggle" data-k-paren></span>。→ [洋葱皮](/zhHans/onion-skin)

**图层锁定、透写台和文字图层在哪里？**
没有图层锁定。用 [洋葱皮](/zhHans/onion-skin) 透看画稿，用 [文字工具](/zhHans/tools?id=文字) 把文字写进画稿里。

## 界面

**面板不见了 / 布局乱了。**
在 **设置**（⚙）→ **面板** 里重新打开面板，或按 **重置工作区布局**。→ [界面与面板](/zhHans/screen)

**想更改应用的语言。**
[偏好设置](/zhHans/preferences) → **语言** → **程序语言**。印在摄影表上的语言用 **标注语言** 另外设置。

**想用和以前的应用一样的快捷键。**
在 **设置** → **键盘快捷键** 里选择 **基于 CLIP STUDIO** 或 **基于 TVPaint** 预设，或者导入那个应用的快捷键文件。→ [快捷键](/zhHans/shortcuts)

## 播放与声音

**播放时总是停顿。**
默认的播放方式（**所有帧**）会等每张画稿准备好。想保持时间播放，用 **跳帧**；想先全部画好，用 **播放前渲染**。→ [播放与录音](/zhHans/playback?id=播放方式)

**没有声音。**
在 [偏好设置](/zhHans/preferences) → **音频** 里确认 **输出** 设备。如果播放时出现“{n}个音频无法播放”，说明那个声音文件丢失、还在下载中，或格式无法读取。

**用无线耳机时，声音和画面对不上。**
用 **A/V 偏移** 对齐。→ [播放与录音](/zhHans/playback?id=声音和画面错开时)

**录不了音。**
打开 [偏好设置](/zhHans/preferences) → **音频** → **允许麦克风**，并在系统设置里也允许 Anicel 使用麦克风。

## 导出

**部分视频格式是灰色的。**
这是因为本设备的系统不支持该编解码器。如果这台电脑的 PATH 里有 **FFmpeg**，就可以用它导出。→ [导出](/zhHans/export)

**导出的视频没有声音。**
在序列标签页的 **音频** 下打开 **将 SE 混音封装进视频**。静音的 SE 行不会导出。
