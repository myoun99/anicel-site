# 动画图层

基本图层：在每个单元格里画一张画稿，让它动起来。新项目里的 **A** 就是这种图层。

![](img/timeline.png)

## 块与单元格

- 横向一个单元格就是一帧。一个彩色的 **块** 是一张画稿，块的长度就是这张画稿显示的格数。
- 块里的大数字是 **画稿名称**；块末端的小数字是它的 **长度**。
- 没有块的单元格是 **空单元格**（什么都不显示；摄影表上为 ×）。
- 新图层的名称是 **A · B · C …**，颜色标签一开始是 **Layout Material**。→ [颜色标签与 Take](/zhHans/layer-labels)

## 制作画稿

- 选中一个单元格，按 **帧** 胶囊上的 **＋** 新建帧 <span data-k="frame-new-drawing" data-k-paren></span>：那个单元格里会出现一张新画稿。在块的中间按，块会在那里一分为二。
- 打开 **✦**（自动创建帧）后，只要在空单元格里画，就会生成画稿。
- 拖动块末端的三角形可以改变长度。用 **1 · 2 · 3 · 4 · N** 格 <span data-k="timeline-comma-1 timeline-comma-2 timeline-comma-3 timeline-comma-4 timeline-comma-n" data-k-paren></span> 可以一次设定所有选中块的长度。后面的块会相应地收拢或后移。
- **推出（空出帧） / 拉回（收拢帧）** 会在选中的位置空出或收拢空单元格。
- **×**（清空）把选中的单元格变成空单元格。

## 同名 = 同一张画稿

- 画稿名称相同的块就是 **同一张画稿**。改其中一个，另一个也会跟着变（就像摄影表上的重复标记）。
- 把块改成已经存在的名称时，会询问 **要链接的帧**。
- **粘贴链接** <span data-k="edit-paste-linked" data-k-paren></span> 作为同一张画稿粘贴；**粘贴独立** <span data-k="edit-paste-independent" data-k-paren></span> 作为新画稿粘贴。要把链接的画稿分开，用 **取消链接**。→ [时间轴](/zhHans/timeline?id=共用胶囊)
- **自动命名** 从起始编号开始，按顺序给选中的块命名。

## 连续块末端的 ＋、保持与重复

在 **连续块** — 中间没有空单元格、连在一起的块 — 的两端，有一个小 **＋** 和一个端点标记。

- **＋**：点一下在末端加一张画稿，拖动则拖多少加多少。
- 点端点标记，选择连续块外面的空单元格怎么处理。结果会以 **淡色块** 填到镜头的结尾（或开头）。

| 端点 | 作用 |
|---|---|
| 无 | 空单元格保持为空 |
| **保持** | 末端的画稿一直显示到镜头结尾 |
| **重复** | 整个连续块重复到镜头结尾 |
| **重复所选** | 只重复连续块中选中的部分（有选中范围时） |

淡色块会随着连续块的变化自动重新计算。编辑连续块或改变镜头长度时，它们会跟着变。

## 中间画标记

用来指示中间画（夹在中间的画稿）的标记。有两种：○ 和 ●。

- **○ 中间画标记1 · ● 中间画标记2**：在选中的单元格上加上或去掉标记。
- **自动添加中间画标记**：设定间隔 n 和 ○/●，选中的块会从开头起每 n 格加一个标记。
- **没有名称的画稿** 在块的开头显示标记而不是名称。显示为 ○ 还是 ●，在 [偏好设置](/zhHans/preferences) → **Display** → **Mark of an unnamed block** 里选择（自动添加窗口一开始也会选这个标记）。

## 这个图层能做的事

作为附属图层的主图层 · 剪贴 · [洋葱皮](/zhHans/onion-skin) · [效果与变换](/zhHans/effects) · 混合 · 不透明度。
