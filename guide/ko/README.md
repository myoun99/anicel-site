콘티부터 촬영까지, 한 컷을 프로젝트 파일 하나에서 이어서 작업합니다. 다만 **동화 · 시아게 · 촬영**은 지금 버전으로는 전용 프로그램을 완전히 대신하기에 아직 기능이 부족합니다. 기능은 업데이트마다 계속 늘어납니다. 원하시는 기능이나 피드백이 있으면 [**의견 보내기**](/ko/feedback)(⚙ 설정 메뉴)로 보내 주세요. 적극 검토하겠습니다.

- 한 프로젝트에 컷을 여러 개 두고, 캔버스 크기를 컷마다 따로 정합니다 — [컷별 캔버스 크기](/ko/canvas-size)
- 레이어: 애니메이션 · 콘티 · 이미지 · 폴더 · 조정 · SE · 디렉션 · 카메라 · 트랜지션, 그리고 본 레이어에 붙는 어태치 — [레이어 한눈에](/ko/layers)
- 레이어와 컷에 색 라벨 · 테이크를 붙입니다 — [색 라벨과 테이크](/ko/layer-labels)
- 타임시트 · 콘티 용지 · 컷 봉투를 작업 화면에서 보고 출력합니다 — [타임시트 · 콘티 용지 · 컷 봉투](/ko/sheets)
- 소리 파일을 SE 레이어로 놓고, 마이크로 녹음합니다 — [사운드(SE) 레이어](/ko/sound-layers) · [재생과 녹음](/ko/playback)
- CLIP STUDIO(.sut) · Photoshop(.abr) 브러시를 가져옵니다 — [브러시](/ko/brushes)
- TVPaint(.tvpp) · CLIP STUDIO(.clip) 파일을 프로젝트로 엽니다 — [열기와 저장](/ko/files)
- 동영상(MP4 · MOV) · 연번 그림 · 셀 · 타임시트 · 콘티 용지(PDF)로 출력합니다 — [출력](/ko/export)
