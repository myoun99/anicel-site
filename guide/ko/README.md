# Anicel

손그림 애니메이션을 콘티부터 작화·타임시트·소리·출력까지 한 파일에서 만드는 앱입니다.

## 강점

- **콘티를 그리면 그대로 컷이 된다** — [콘티](/ko/storyboard)
- **타임시트·콘티 용지를 출력 모습 그대로 보며 작업** — [타임시트·콘티 용지](/ko/sheets)
- **공정이 색으로 보인다** — [색 라벨](/ko/layer-labels)
- **그림자·하이라이트는 본 그림에 붙여서** — [어태치 레이어](/ko/attach-layers)
- **컷마다 다른 캔버스 크기** — [컷별 캔버스 크기](/ko/canvas-size)
- **소리를 레이어로 놓고 파형을 보며 타이밍** — [사운드 레이어](/ko/sound-layers)
- **동영상·셀·타임시트·콘티 용지까지 한 창에서 출력** — [출력](/ko/export)
