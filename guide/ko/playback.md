## 재생 방식

그림이 아직 준비되지 않은 프레임에 닿았을 때 어떻게 할지를 **설정**(⚙) → **프로젝트 설정** → **재생 방식** 에서 고릅니다.

| 방식 | 하는 일 |
|---|---|
| **모든 그림**(기본) | 그림이 준비될 때까지 그 앞에서 잠깐 기다렸다가 이어 갑니다. 그림을 건너뛰지 않습니다 |
| **건너뛰기** | 시간을 지키고, 제때 못 그린 그림은 건너뜁니다(소리와 시간이 정확) |
| **재생 전 렌더링** | 앞으로 재생할 구간을 먼저 다 그려 두고 시작합니다 |

건너뛰기로 재생하면 건너뛴 그림 수가 「{n} 건너뜀」으로 표시됩니다.

## 녹음

![](img/icon-playback-record-voice-button.png ':class=icon :no-zoom') 재생 버튼 옆의 **마이크** 로 대사 · 효과음을 녹음합니다. 녹음은 **재생하면서 소리를 받는 것** 입니다 — 그림과 다른 소리를 보고 들으며 맞춰 녹음합니다.

### 처음 한 번

1. [환경설정](/ko/preferences?id=오디오) → **오디오** → **마이크 허용** 을 켭니다. 꺼져 있으면 마이크를 눌러도 「마이크가 허용되어 있지 않습니다」만 뜹니다.
2. OS 가 마이크 권한을 물으면 허용합니다. 거절했다면 OS 설정에서 Anicel 의 마이크를 켭니다.
3. 같은 곳의 **입력** 에서 마이크를 고르고, 말해 보며 **입력 레벨** 이 움직이는지 봅니다.

### 녹음하기

1. 녹음을 놓을 **SE 줄** 에 섭니다. 다른 줄에 서 있으면 **새 SE 줄** 이 생겨 거기에 놓입니다.
2. 플레이헤드를 시작할 자리에 둡니다(재생 중이어도 됩니다 — 누른 자리부터).
3. **마이크**<span data-k="voice-record-toggle" data-k-paren></span> 를 누릅니다 → 그 자리부터 재생이 돌며 녹음됩니다. 녹음하는 동안 블록과 파형이 자라며 보입니다.
4. **마이크** 를 다시 누르거나 **정지** 하면 멈추고, 그 테이크가 SE 줄에 블록으로 놓입니다.

| 알아 둘 것 | |
|---|---|
| 들리는 소리 | 다른 줄의 소리는 그대로 들리고, **녹음 중인 줄** 의 소리만 꺼집니다 |
| 이미 블록이 있는 자리 | 새 테이크가 그 구간을 이깁니다 — 겹친 부분만 잘려 나가고, 원래 소리 파일은 미디어 패널에 남습니다 |
| 되돌리기 | 실행 취소 한 번이면 테이크와 잘린 블록이 모두 돌아옵니다 |
| 테이크가 있는 곳 | 프로젝트 파일 안 · 미디어 패널 |
| 소리가 너무 컸을 때 | 한 번이라도 깨지면 마이크 오른쪽 위에 **빨간 점** 이 켜집니다. **클리핑 주의 안내** 를 켜 두면 알림과 블록의 빨간 모서리도 |

### 정해진 구간만 녹음하기 (펀치 인)

SE 줄에서 녹음할 구간을 **범위로 고르고**, 그보다 앞에 플레이헤드를 두고 마이크를 누릅니다. 재생은 플레이헤드부터 돌지만 녹음은 **범위 안에서만** 됩니다 — 앞부분을 들으며 들어갈 때를 잡습니다.

| 신호 (환경설정 → 오디오) | 처음 | 하는 일 |
|---|---|---|
| **큐 비프** | 켬 | 범위 시작 전 1초 간격으로 「삐 · 삐 · 삐」 — 세 번째 바로 뒤가 시작 |
| **스트리머** | 켬 | 시작 전 최대 3초 동안 화면을 가로질러 띠가 지나가고, 끝에 닿는 순간이 시작 |

### 바로 시작하지 않으려면 (카운트인)

**카운트인**(처음 0초 = 끔)에 초를 정해 두면, 마이크를 누른 뒤 그만큼 기다렸다가 재생이 시작됩니다(큐 비프가 켜져 있으면 기다리는 동안 삐 소리). 범위를 고른 녹음에는 쓰이지 않습니다.

### 소리를 다듬는 설정 (환경설정 → 오디오)

| 설정 | 처음 | |
|---|---|---|
| **마이크 게인** | 0 dB | 받는 소리의 크기 |
| **입력 채널** | 장치 그대로 | 모노 믹스 / 왼쪽만 / 오른쪽만 |
| **잡음 제거** | 끔 | 목소리용 — 발소리 · 소품 소리까지 지우므로 효과음을 녹음할 때는 끕니다 |
| **클리핑 주의 안내** | 끔 | 깨진 테이크를 알림 + 블록 모서리를 빨갛게 |

게인 · 입력 채널은 녹음을 시작할 때의 값으로 한 테이크를 끝까지 받습니다. 녹음 중에 바꾸면 다음 테이크부터입니다.

## 소리와 그림이 어긋날 때

- **A/V 오프셋**(환경설정 → 오디오): 그림을 소리보다 몇 프레임 늦게 · 빠르게 보일지 미세 조정합니다. 무선 이어폰은 소리가 150~300ms 늦게 나는 일이 흔하므로, 이어폰으로 들을 때 어긋나면 여기서 맞춥니다.
- **출력** · **입력**: 쓸 스피커와 마이크를 고릅니다.
- 소리가 안 나는 블록은 재생 중 「소리 n개 못 냄」으로 알려 줍니다(파일이 없거나, 아직 내려받는 중이거나, 읽을 수 없는 형식).
