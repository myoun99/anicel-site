# 색

| | |
|---|---|
| ![](img/icon-rail-group-rail-R1.png ':class=icon :no-zoom') | 오른쪽 띠 맨 위 버튼. 앞 동그라미 = **그리는 색**, 뒤 동그라미 = **배경색**(누르면 두 색이 맞바뀝니다) |

| 컬러 휠 | RGB | 팔레트 |
|---|---|---|
| ![](img/panel-color-wheel.png ':class=panel') | ![](img/panel-color-rgb.png ':class=panel') | ![](img/panel-color-palette.png ':class=panel') |

- **컬러 휠** — 고리는 색조, 삼각형은 채도 · 밝기. 아래에 **최근** 10색과 **기본 팔레트** 가 붙어 있습니다.
- 맨 아래 줄의 16진수 · R · G · B 숫자를 누르면 직접 입력합니다.
- **팔레트** — 칸을 누르면 그 색, **빈 칸을 누르면 지금 색이 그 칸에** 들어갑니다. 칸을 끌면 자리가 옮겨집니다. **−** 는 지금 색 빼기, **⋯** 에 **기본 팔레트로**(휠 · RGB 탭 아래에 붙는 것) · **복제** · **삭제**.
- **최근** — 획에 쓴 색이 새것부터 쌓입니다.

## 이미 그린 그림의 색 바꾸기

타임라인 공용 알약의 **색 편집** 에서 고른 범위의 그림을 한꺼번에 바꿉니다. → [타임라인](/ko/timeline)

| 항목 | 하는 일 |
|---|---|
| 색 변환 | 그림의 색을 지금 색으로(투명도는 그대로 — 선 색 바꾸기) |
| 색 삭제 · 색 남기기 | 지금 색인 부분만 지우거나, 지금 색만 남기고 지웁니다(허용차 조절) |
| 픽셀 비우기 | 그림을 비웁니다 |
| 2치화 | 반투명한 가장자리를 없앱니다 — 임계값 이상은 불투명, 미만은 투명 |
| 픽셀 잘라내기 · 복사 · 위 붙여넣기 · 아래 붙여넣기 | 그림 단위로 옮기기 |
