# 레이어 한눈에

타임라인에서 **한 줄이 레이어 하나** 입니다. 줄은 세 구역으로 나뉘고, 왼쪽 세로 띠에 구역 이름이 적혀 있습니다.

| 구역 | 화면 위치 | 들어가는 레이어 |
|---|---|---|
| **CAM**(카메라) | 맨 위 | 카메라 · 트랜지션 · 디렉션 |
| **SE**(효과음 · 대사) | 가운데 | SE |
| **ACTION**(그림) | 아래 | 애니메이션 · 콘티 · 이미지 · 폴더 · 조정 레이어 |

구역 이름은 종이 타임시트의 칸 이름과 같습니다. [X시트](/ko/timeline?id=x시트)로 바꾸면 종이 시트처럼 왼쪽부터 ACTION · SE · CAM 순서로 세로 열이 됩니다.

## 레이어 종류

| 종류 | 한 줄 설명 | 자세히 |
|---|---|---|
| **애니메이션** | 그림을 칸마다 그리는 기본 레이어 | [애니메이션 레이어](/ko/animation-layers) |
| **콘티** | 콘티 그림. 블록 하나가 콘티 용지의 한 칸 | [콘티 레이어](/ko/conte-layer) |
| **이미지** | 배경 같은 그림 한 장을 컷 전체에 | [이미지 레이어](/ko/image-layers) |
| **폴더** | 레이어를 묶어 함께 보이고 숨기고 움직이기 | [폴더](/ko/folders) |
| **조정 레이어** | 아래 레이어 전체에 효과(밝기 · 색조 · 흐림 …) | [조정 레이어](/ko/adjustment-layers) |
| **SE** | 소리 · 대사. 파형을 보며 타이밍 맞추기 | [사운드(SE) 레이어](/ko/sound-layers) |
| **디렉션** | PAN · FIX 같은 카메라 지시를 시트에 적기 | [카메라 · 디렉션 · 트랜지션](/ko/camera-section) |
| **카메라** | 카메라워크(위치 · 비율 · 회전). 컷마다 하나, 저절로 있음 | 〃 |
| **트랜지션** | FI · FO · O.L 같은 화면 전환. 트랙에 하나, 저절로 있음 | 〃 |
| **어태치**(종류가 아니라 붙이는 방식) | 본 레이어에 붙어 움직임 · 효과를 함께 따르는 레이어(그림자 · 하이라이트) | [어태치 레이어](/ko/attach-layers) |

> 새 레이어의 기본 이름: 애니메이션은 **A · B · C …**, 이미지는 **BG**(이미 있으면 **BOOK**), 콘티는 **Conte**, 조정 레이어는 **FX1**, SE 는 **S1 · S2**, 디렉션은 **Direction 1**, 폴더는 **Folder 1**, 카메라 · 트랜지션은 **Camera** · **Transition**. 업계 표기를 따라 어느 언어 화면에서든 같은 이름입니다.

## 레이어 만들기

타임라인 위쪽 **레이어** 알약에서 만듭니다.

- **＋** 새 레이어<span data-k="layer-add" data-k-paren></span>: 애니메이션 레이어. [콘티 패널](/ko/storyboard)에서는 SE 레이어.
- **＋ ▾**: 종류를 골라 만듭니다 — 애니메이션 · 콘티 · 이미지 · SE · 디렉션 · 조정 레이어 · 폴더, 그리고 지금 레이어의 위/아래에 붙는 **프리 / 싱크 어태치 레이어**.

## 레이어 줄의 칸

![](img/layer-row.png ':size=465')

줄 왼쪽(레일)에 왼쪽부터 이런 칸이 있습니다. 종류에 맞지 않는 칸은 비어 있습니다.

| 칸 | 하는 일 |
|---|---|
| **색 라벨** | 공정(콘티 · 원화 · 동화 …). → [색 라벨과 테이크](/ko/layer-labels) |
| **테이크** | T1~T9 |
| **▸** | 레인(변형 · 이펙트 …)을 펼칩니다. → [이펙트와 변형](/ko/effects) |
| **시트 화살표** | 이 레이어를 [타임시트](/ko/sheets)에 올릴지 · 내릴지 |
| **종류 아이콘 · 이름** | 이름을 **더블클릭** 하면 바뀝니다. 이름 옆에 링크 🔗 · 그래프 · 접기 같은 작은 버튼이 붙기도 합니다 |
| **클리핑** | 아래 레이어로 클리핑(아래 레이어의 그림 안에만 보이게) |
| **FX** | 이 레이어의 이펙트를 한꺼번에 우회 / 적용 |
| **어니언** | 이 레이어의 어니언 스킨. → [어니언 스킨](/ko/onion-skin) |
| **눈** | 숨기기 / 표시 |
| **불투명도** | 막대를 끌어 0~100% |
| **블렌드** | 합성 방식(표준 · 곱하기 · 스크린 · 오버레이 …). 폴더는 **통과** 가 기본 |

- 눈 · 어니언 · 클리핑 · FX · 시트 같은 켜고 끄는 칸은 **누른 채 위아래로 쓸면** 지나간 줄이 모두 같은 상태로 바뀝니다.

### 맨 위 머리 줄 (모든 레이어에 한꺼번에)

레일 맨 위 줄의 각 칸을 누르면 그 칸에 대한 메뉴가 열립니다.

| 칸 | 메뉴 |
|---|---|
| 구역 | SE 행 표시 · 카메라 행 표시 |
| 시트 | 모두 시트에 올리기 / 내리기 · 시트 켜진 행 솔로 |
| 색 라벨 | 색 솔로 · 마크 필터 해제 |
| 종류 | 종류 솔로 |
| 클리핑 | 클리핑 모두 해제 · 클리핑 솔로 |
| FX | FX 모두 적용 / 우회 · FX 켜진 행 솔로 |
| 어니언 | 표시 중인 레이어에 어니언 스킨 적용 / 해제 · 어니언 스킨 패널 열기 |
| 눈 | 모두 표시 / 숨기기 |
| 불투명도 · 블렌드 | 표시 중인 레이어 전체에 |

**솔로** 는 조건에 맞는 줄만 남기고 나머지를 잠시 숨깁니다. 한 번 더 누르면 풀립니다.

## 고르기 · 옮기기 · 지우기

- 이름을 누르면 그 레이어가 **지금 레이어**(그리는 곳)가 됩니다. 끌면 여러 줄을 고릅니다.
- 고른 줄을 다시 끌면 **순서가 바뀝니다.** 폴더 위에 놓으면 그 폴더 안으로 들어갑니다.
- 구역을 넘어 옮길 수는 없습니다(그림 레이어를 SE 구역으로 등). CAM 구역은 위에서부터 카메라 · 트랜지션 · 디렉션 순서가 고정이고, 디렉션끼리만 순서를 바꿉니다.
- 복제 · 잘라내기 · 복사 · 붙여넣기 · 삭제는 공용 알약에서 합니다. → [타임라인](/ko/timeline?id=공용-알약)
- 레이어 이름은 **편집**<span data-k="edit-instance" data-k-paren></span>으로도 바꿉니다. 여러 줄을 고르고 편집하면 한꺼번에 바뀝니다.

## 레이어에 없는 것

- **레이어 잠금** 은 없습니다.
- **라이트 테이블** 은 없습니다. 다른 그림을 비춰 보는 것은 [어니언 스킨](/ko/onion-skin)으로 합니다.
- **텍스트 레이어** 는 없습니다. 글자는 [텍스트 도구](/ko/tools?id=텍스트)로 그림 안에 넣습니다.
