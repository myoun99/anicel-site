# 프로젝트 설정

**설정**(⚙) 메뉴 위쪽 두 줄은 **이 프로젝트에만** 적용됩니다(파일에 저장). 앱 전체에 적용되는 것은 [환경설정](/ko/preferences)입니다.

## 작품 설정

![](img/work-settings.png ':size=460')

- 제목 · 화수는 타임시트 · 콘티 용지 · 컷 봉투의 머리에 찍힙니다.
- **표지 그림** 은 [미디어 패널](/ko/media-pool)의 그림에서 고릅니다.
- **스태프 설정**: 공정마다 담당자. 컷마다 다르면 **컷** 알약 → **컷 설정** 에서.

## 프로젝트 설정

![](img/menu-project-settings.png ':size=496')

줄마다 지금 값이 보이고, 누르면 그 값을 바꾸는 창이 열립니다.

| 줄 | |
|---|---|
| **FPS** | 소리가 있는 프로젝트에서 23.976 ↔ 24 처럼 바꾸면 소리를 어떻게 할지 묻습니다: **오디오 타이밍 유지** / **오디오 0.1% 당김** |
| **샘플레이트** | 44.1 · 48 · 96 kHz |
| **카메라** | 카메라 틀의 크기(프로젝트 공통). **캔버스에서 조정** 으로 캔버스 위에서 끌어 정할 수도 있습니다. 캔버스(그리는 용지)의 크기는 컷마다 따로 → [컷별 캔버스 크기](/ko/canvas-size) |
| **재생 방식** | 그림이 준비 안 된 프레임에서: **모든 그림**(기본) · **건너뛰기** · **재생 전 렌더링** → [재생과 녹음](/ko/playback) |
