# 터치와 펜

모두 [환경설정](/ko/preferences) → **입력** 에서 바꿉니다.

![](img/prefs-input.png ':size=720')

## 손가락 (캔버스)

| 손가락 | 기본 동작 | 고를 수 있는 것 |
|---|---|---|
| 한 손가락 끌기 | **넘기기** — 좌우로 이전 · 다음 그림, 위아래로 위 · 아래 레이어 | 넘기기(프레임/레이어) · 화면 · 브러시 크기 · 터치로 그리기 · 없음 |
| 두 손가락 | **화면** — 이동 · 확대 · 회전 | |
| 세 손가락 | **브러시 크기** — 위아래로 끌기 | |

- 끄는 도중 **손가락을 하나 더 대면** 한 단계 더 세밀해집니다: 넘기기는 한 칸씩, 화면은 줌 · 회전이 단계에 붙고, 브러시 크기는 [툴 사이즈](/ko/brushes?id=툴-사이즈)에 붙습니다(**손가락 추가 모디파이어**, 기본 켬).
- **터치로 그리기** 는 한 손가락에만 줄 수 있습니다. 펜이 없는 기기에서 손가락으로 그릴 때 씁니다.
- **모든 터치 무시** 를 켜면 캔버스가 손가락에 반응하지 않습니다(펜만).

### 탭

| 탭 | 동작 |
|---|---|
| 두 손가락 탭 | 실행 취소 |
| 세 손가락 탭 | 다시 실행 |
| 네 손가락 탭 | 재생 / 정지 |

두 · 세 손가락 **길게 누르기** 에는 원하는 동작을 줄 수 있습니다.

### 그 밖의 항목

| 항목 | 내용 |
|---|---|
| 플립 진동 | 넘기기가 다른 그림에 닿을 때마다 짧게 진동(진동자가 있는 기기만) |
| 두 손가락 회전 | 끄면 두 손가락은 이동과 줌만 합니다(회전 버튼 · 키는 그대로) |
| 모디파이어가 회전을 잠금 | 켜면 추가 손가락이 각도를 고정합니다(이동 + 단계 줌). 끄면(기본) 각도가 단계에 붙습니다 |
| 회전 스냅 · 줌 스냅 | 단계 값 |
| 최대 줌 잠금 | 이 배율 넘게 확대되지 않게(화면에 맞추기도 여기서 멈춥니다) |

## 손가락을 키 대신 쓰기

키보드가 없는 태블릿에서는 펜으로 작업하는 동안 **화면 어디든 대고 있는 다른 손가락** 이 <kbd class="k-pc">Shift</kbd><kbd class="k-mac">⇧</kbd> · <kbd class="k-pc">Alt</kbd><kbd class="k-mac">⌥</kbd> 대신입니다.

- 펜으로 끄는 동안 손가락을 대면 <kbd class="k-pc">Shift</kbd><kbd class="k-mac">⇧</kbd> — 이동은 한 방향으로, 도형은 비율 고정이 뒤집힙니다. 획을 45°로 곧게 하려면 **손가락 스트로크 모디파이어** 를 켭니다(기본 끔).
- 변형 상자의 모서리를 끌 때 손가락을 대면 <kbd class="k-pc">Alt</kbd><kbd class="k-mac">⌥</kbd> — 반대쪽 모서리를 기준으로 크기가 바뀝니다.

## 펜과 마우스 버튼

| 버튼 | 기본 | 고를 수 있는 것 |
|---|---|---|
| 우클릭 / 펜 사이드 버튼 | 스포이트 | 스포이트 · 지우개 · 손바닥 · 실행 취소 · 다시 실행 · 없음 |
| 휠 클릭 / 펜 위쪽 버튼 | 없음 | 〃 |
| 펜 엉덩이(펜을 뒤집기) | 지우개 | 〃 |

- 버튼을 떼면 원래 도구로 돌아갈지(**도구로 복귀**), 그 도구로 남을지(**유지**) 고릅니다.
- Apple Pencil 의 더블탭(브러시 ⇄ 지우개)은 iPad 시스템 설정을 따릅니다.
