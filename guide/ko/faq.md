# 자주 묻는 것

## 저장 · 파일

**앱이 꺼졌는데 작업이 없어졌어요.**
자동 저장은 처음에는 꺼져 있습니다. [환경설정](/ko/preferences) → **자동 저장** 을 켜 두면 정한 주기마다 저장됩니다. → [열기와 저장](/ko/files?id=자동-저장)

**저장에 실패했다고 나와요.**
그때까지의 작업은 앱 안의 **실패본** 에 있습니다. 앱을 닫기 전에 **프로젝트** → **실패본 백업** 또는 **다른 이름으로 저장** 으로 다른 곳에 남기세요. → [열기와 저장](/ko/files?id=저장이-안-될-때-실패본)

**다른 기기에서 열었더니 그림 · 소리 · 영상 일부가 없어요.**
「참조」로 들여온 파일은 원본이 프로젝트 파일 바깥에 있습니다. 미디어 패널의 **폴더에서 찾기** 로 다시 잇거나, 옮기기 전에 **프로젝트 파일에 품기** 를 해 두세요. → [미디어 패널과 임포트](/ko/media-pool?id=참조-파일을-못-찾을-때)

**Google 드라이브 · Dropbox 의 파일을 바로 열 수 있나요?**
네. **파일 열기** 창에서 드라이브 · Dropbox 에 있는 프로젝트 파일을 고르면 열립니다. 폴더를 고르는 창에서는 기기에 따라 드라이브를 못 고르고, 출력도 기기와 파일 수에 따라 다릅니다 — 표는 [열기와 저장 › 클라우드 · 태블릿에서](/ko/files?id=클라우드-·-태블릿에서)와 [출력 › Google 드라이브에 바로 내기](/ko/export?id=google-드라이브에-바로-내기)에 있습니다.

**TVPaint · CLIP STUDIO 파일을 열 수 있나요?**
`.tvpp` · `.clip` 을 **파일 열기** 로 열면 새 프로젝트로 들어옵니다. 원본은 바뀌지 않습니다. → [열기와 저장](/ko/files)

## 그리기

**그려지지 않아요.**
- 지금 레이어가 그림을 받는 레이어인지 보세요. 폴더 · 조정 레이어 · SE · 카메라 줄, 그리고 파일 그대로 놓인 **참조 이미지 레이어** 에는 그려지지 않습니다(참조 이미지는 **래스터라이즈** 하면 그려집니다). → [레이어 한눈에](/ko/layers)
- 빈 칸이면 **✦**(프레임 자동 생성)를 켜거나 **프레임 ＋** 로 그림을 먼저 만드세요.

**필압이 먹지 않아요(Windows).**
[환경설정](/ko/preferences) → **입력** → **태블릿 서비스** 를 **표준** ↔ **Wintab** 으로 바꿔 보세요.

**펜 옆 버튼을 누르면 스포이트가 돼요.**
기본값입니다. [환경설정](/ko/preferences) → **입력** → **캔버스** 에서 바꿉니다. → [터치와 펜](/ko/touch-pen)

**앞 그림이 비쳐 보이지 않아요.**
어니언 스킨은 **레이어마다** 켭니다. 그 레이어 줄의 어니언 칸이나 **어니언 스킨 켜기/끄기**<span data-k="onion-skin-toggle" data-k-paren></span>. → [어니언 스킨](/ko/onion-skin)

**레이어 잠금 · 라이트 테이블 · 텍스트 레이어는 어디 있나요?**
레이어 잠금은 없습니다. 비춰 보기는 [어니언 스킨](/ko/onion-skin)으로, 글자는 [텍스트 도구](/ko/tools?id=텍스트)로 그림 안에 넣습니다.

## 화면

**패널이 사라졌어요 / 배치가 엉켰어요.**
**설정**(⚙) → **패널** 에서 패널을 다시 켜거나 **작업공간 배치 초기화** 를 누르세요. → [화면과 패널](/ko/screen)

**화면 언어를 바꾸고 싶어요.**
[환경설정](/ko/preferences) → **언어** → **프로그램 언어**. 타임시트에 찍히는 언어는 **표기용 언어** 로 따로 정합니다.

**쓰던 앱과 단축키를 같게 하고 싶어요.**
**설정** → **키보드 단축키** 에서 **클립 스튜디오 기반** · **TVPaint 기반** 프리셋을 고르거나, 그 앱의 단축키 파일을 가져오세요. → [단축키](/ko/shortcuts)

## 재생 · 소리

**재생이 중간중간 멈춰요.**
기본 재생 방식(**모든 그림**)은 그림이 준비될 때까지 기다립니다. 시간을 지키며 재생하려면 **건너뛰기**, 먼저 다 그려 두려면 **재생 전 렌더링**. → [재생과 녹음](/ko/playback?id=재생-방식)

**소리가 안 나요.**
[환경설정](/ko/preferences) → **오디오** 의 **출력** 장치를 확인하세요. 재생 중 「소리 n개 못 냄」이 뜨면 그 소리 파일이 없거나, 아직 내려받는 중이거나, 읽을 수 없는 형식입니다.

**무선 이어폰으로 들으면 소리와 그림이 어긋나요.**
**A/V 오프셋** 으로 맞춥니다. → [재생과 녹음](/ko/playback?id=소리와-그림이-어긋날-때)

**녹음이 안 돼요.**
[환경설정](/ko/preferences) → **오디오** → **마이크 허용** 을 켜고, OS 설정에서 Anicel 의 마이크 권한도 허용하세요.

## 출력

**동영상 형식 일부가 회색이에요.**
이 기기의 OS 가 그 코덱을 지원하지 않는 경우입니다. 이 컴퓨터의 PATH 에 **FFmpeg** 가 있으면 그것으로 낼 수 있습니다. → [출력](/ko/export)

**출력한 영상에 소리가 없어요.**
시퀀스 탭의 **오디오** 에서 **SE 믹스를 영상에 먹싱** 을 켜세요. 음소거한 SE 줄은 빠집니다.
