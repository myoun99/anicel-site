# 이미지 레이어

배경 같은 이미지를 레이어로 놓습니다.

![](img/overview-cut2.png)

- 왼쪽 위 **프로젝트**(폴더) → **파일 열기…** 로 이미지를 고르거나, 파일을 창에 끌어다 놓으면 **임포트** 창이 열립니다. 줄마다 **넣을 곳**(새 레이어·새 컷·미디어)을 정하고 **임포트** 를 누르면 지금 컷에 이미지 레이어가 생깁니다.
- 가져온 파일은 [미디어 풀](/ko/media-pool)에도 등록됩니다. **래스터라이즈** 를 켜고 들이면 그림으로 구워 넣고 풀에는 남기지 않습니다.
- `A1.png`·`A2.png` 처럼 번호가 이어진 그림은 하나만 골라도 전부 한 레이어의 프레임으로 들어옵니다. 범위는 미리보기의 IN/OUT 으로 고릅니다.
- PSD 는 레이어를 그대로 살려 들입니다.
- 파일 그대로 놓인 이미지 레이어는 레인 맨 위의 **참조**(위치·비율·회전)로 놓는 자리를 정합니다. **변형** 도구로 그 줄을 잡으면 캔버스에 상자가 뜹니다.
