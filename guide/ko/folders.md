# 폴더

![](img/folder.png ':size=1188')

여러 레이어를 묶어 한꺼번에 보이고 숨기고, 불투명도 · 블렌드 · 이펙트 · 변형을 함께 겁니다.

## 만들기와 넣기

- **레이어 ＋ ▾ → 폴더** 로 빈 폴더를 만듭니다(이름은 **Folder 1** …).
- 레이어 줄을 끌어 폴더 줄 위에 놓으면 **그 폴더 안으로** 들어갑니다. 끌어서 폴더 바깥에 놓으면 빠집니다.
- 폴더 안에 폴더를 넣을 수 있습니다.
- 이름 끝의 접기 버튼으로 폴더를 접고 펼칩니다.

## 폴더 줄에서 되는 것

| 칸 | 하는 일 |
|---|---|
| 눈 | 안의 레이어를 한꺼번에 숨기기 / 표시 |
| 불투명도 | 폴더 전체의 불투명도 |
| 블렌드 | 아래 「통과와 다른 블렌드」 |
| 클리핑 | 폴더째로 아래 레이어에 클리핑 |
| FX · 레인 | 폴더 전체에 [이펙트와 변형](/ko/effects) |

- 폴더에는 그림을 그리지 않습니다(칸이 없습니다).
- 변형 도구로 폴더를 고르면 안의 레이어가 모두 같이 움직입니다.
- 폴더는 복사 · 붙여넣기가 되지 않습니다.

## 통과와 다른 블렌드

- **통과**(기본): 폴더가 없는 것처럼, 안의 레이어가 하나씩 아래 그림과 섞입니다. 안의 [조정 레이어](/ko/adjustment-layers)는 폴더 밖 아래 레이어에도 효과를 줍니다.
- **표준 · 곱하기 …**(통과 외): 폴더 안을 먼저 한 장으로 합친 다음, 그 한 장을 고른 방식으로 아래와 섞습니다. 안의 조정 레이어는 폴더 안에만 효과를 줍니다.
