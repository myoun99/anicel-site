# 단축키

기본 키입니다. 화살표와 **W A S D** 는 같은 일을 합니다.

## 이동

| 동작 | 키 |
|---|---|
| 위 레이어 | <kbd>↑</kbd> 또는 <kbd>W</kbd> |
| 아래 레이어 | <kbd>↓</kbd> 또는 <kbd>S</kbd> |
| 이전 블록 | <kbd>←</kbd> 또는 <kbd>A</kbd> |
| 다음 블록 | <kbd>→</kbd> 또는 <kbd>D</kbd> |
| 이전 프레임 | <kbd>Shift</kbd> + <kbd>←</kbd> 또는 <kbd>Shift</kbd> + <kbd>A</kbd> |
| 다음 프레임 | <kbd>Shift</kbd> + <kbd>→</kbd> 또는 <kbd>Shift</kbd> + <kbd>D</kbd> |

## 코마 수

| 동작 | 키 |
|---|---|
| 1코마로 설정 | <kbd>1</kbd> |
| 2코마로 설정 | <kbd>2</kbd> |
| 3코마로 설정 | <kbd>3</kbd> |
| 4코마로 설정 | <kbd>4</kbd> |
| N코마로 설정… | <kbd>5</kbd> |

- 타임라인·콘티 패널 위쪽의 **1 2 3 4 N** 버튼과 같습니다. 고른 블록 전부(고른 게 없으면 지금 블록)의 길이를 바꾸고, 뒤의 블록은 그만큼 당겨지거나 밀립니다 — `1--2--3--` 를 모두 골라 <kbd>1</kbd> 을 누르면 `123` 이 됩니다.
- <kbd>5</kbd> 는 코마 수를 직접 넣는 창을 엽니다.

## 재생

| 동작 | 키 |
|---|---|
| 재생 / 일시정지 | <kbd>Shift</kbd> + <kbd>X</kbd> |
| 처음으로 | <kbd>Shift</kbd> + <kbd>Z</kbd> |

## 보기

| 동작 | 키 |
|---|---|
| 확대 | <kbd>Shift</kbd> + <kbd>E</kbd> |
| 축소 | <kbd>Shift</kbd> + <kbd>Q</kbd> |
| 어니언 스킨 켜기/끄기 | <kbd>Q</kbd> |
| 활성 레이어 솔로 | <kbd>T</kbd> |

## 편집·도구

| 동작 | 키 |
|---|---|
| 편집([편집 버튼](/ko/timeline?id=편집-버튼)) | <kbd>X</kbd> |
| 브러시 도구 | <kbd>B</kbd> |
| 지우개 도구 | <kbd>E</kbd> |
| 스포이트 도구 | <kbd>I</kbd> |
| 채우기 도구 | <kbd>F</kbd> |
| 가이드 도구 | <kbd>G</kbd> |
| 올가미 선택 | <kbd>Z</kbd> |
| 올가미 잘라내기 | <kbd>C</kbd> |
| 스탬프 | <kbd>V</kbd> |
| 일반 변형 | <kbd>Ctrl</kbd> + <kbd>T</kbd> |
| 자유 변형 | <kbd>Ctrl</kbd> + <kbd>Y</kbd> |
| 브러시 합성 모드(목록 위에서부터) | <kbd>F1</kbd> ~ <kbd>F12</kbd> |

- 맥·아이패드에서는 <kbd>Ctrl</kbd> 대신 <kbd>⌘</kbd> 입니다.

## 알아 둘 것

- **X시트에서는 방향 키가 시트를 따라 돕니다.** 타임라인 위쪽 오른쪽 끝의 **⇄** 로 X시트(세로)로 바꾸면 <kbd>↑</kbd> <kbd>↓</kbd>(W S)가 이전·다음 블록, <kbd>←</kbd> <kbd>→</kbd>(A D)가 아래·위 레이어, <kbd>Shift</kbd> + <kbd>↑</kbd> <kbd>↓</kbd>(W S)가 이전·다음 프레임입니다.
- **재생·처음으로·편집·코마 수 키는 마지막으로 만진 패널의 버튼을 누릅니다.** [콘티](/ko/storyboard) 패널에서는 재생이 트랙 전체를 재생하고, 처음으로가 트랙의 처음으로 가고, 편집이 커서가 있는 블록의 창을 열고(컷이면 컷 이름), 코마 수가 그 블록의 길이를 바꿉니다(컷 블록이면 컷 길이).
- **모든 키는 바꿀 수 있습니다.** 왼쪽 위 **설정**(톱니) → **키보드 단축키…** 에서 전체 목록을 보고 바꿉니다. 직접 바꾼 키가 기본값보다 우선합니다.
