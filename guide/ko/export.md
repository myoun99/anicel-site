# 출력

왼쪽 위 **프로젝트**(폴더) → **내보내기…** 에서 한 창으로 출력합니다.

![](img/export.png)

- 탭: **시퀀스**(동영상·연번 이미지) · **이미지** · **셀** · **콘티 용지**
- 범위(컷/프로젝트)와 크기(카메라/캔버스)는 탭에 따라 고릅니다.
- 동영상은 **코덱** 을 고릅니다(MP4: H.264·H.265, MOV: H.264·ProRes). 이 기기에서 못 쓰는 코덱은 꺼진 채 보입니다.
- 동영상에는 SE 줄의 소리가 함께 들어갑니다(**오디오** 에서 끌 수 있습니다). 음소거한 SE 줄은 빠집니다.
- 파일 이름은 설정 맨 위 **이름** 에 적고, 저장 위치는 **내보내기** 를 누를 때 고릅니다.
- 출력하는 동안에는 창의 설정이 잠기고 **취소** 만 누를 수 있습니다.
- 지금 프레임 한 장만 그림으로 남길 때는 **프로젝트** → **다른 이름으로 저장** → **PNG…**·**JPG…** 를 씁니다.

## 셀

그림 한 장을 파일 한 장(PNG·JPG)으로 냅니다. 타임시트와 컷 봉투도 여기서 냅니다.

![](img/export-cels.png)

- **내보낼 종류** 에서 셀·콘티·미술·디렉션, 타임시트·컷 봉투 중 낼 것을 고릅니다. 타임시트는 PNG·JPG·XDTS 로 냅니다.
- 미리보기 아래 목록에서 줄마다, 그림마다 끄고 켭니다.
- 목록 위 띠에서 그림에 디렉션·카메라 경로·가이드를 겹쳐 냅니다.
- 파일 이름은 레이어 이름과 그림 번호입니다(예: `A1.png`). 폴더·접두사·자릿수·접미사는 **이름 규칙** 에서 고릅니다.
- [어태치 레이어](/ko/attach-layers)는 본 레이어와 합쳐진 한 장으로 나옵니다.
- [색 라벨](/ko/layer-labels)과 테이크로 골라 냅니다(예: 원화의 최신 테이크만).
- [겸용컷](/ko/linked-cuts)은 한 컷으로 다룹니다. 타임시트는 이어진 컷마다 나옵니다.
