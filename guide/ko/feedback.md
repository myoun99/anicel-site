# 의견 보내기

버그 · 원하는 기능 · 쓰면서 느낀 점을 앱에서 바로 보냅니다.

## 보내는 법

1. **설정**(⚙) 메뉴 맨 아래, **Anicel 정보** 밑의 **의견 보내기** 를 누릅니다.
2. 창에서 둘 중 하나를 고릅니다.

| 버튼 | |
|---|---|
| **글만 보내기** | 글만 보냅니다. 로그인하지 않습니다. |
| **사진·동영상 포함 (Google 로그인)** | 스크린샷 · 화면 녹화 같은 이미지 · 동영상을 붙입니다. Google 에 로그인해야 합니다. |

3. 브라우저에 Google 폼이 열립니다. **기기 · OS · OS 버전 · 앱 빌드** 는 미리 채워져 있습니다. 내용을 적고 보냅니다.

- 폼은 영어로 되어 있습니다.
- 붙일 수 있는 것은 이미지와 동영상뿐입니다.
- 컴퓨터 이름 · 사용자 이름 같은 다른 기기 정보는 채워지지 않습니다.

## 이전 파일이 열리지 않을 때

새 버전에서 이전 파일이 열리지 않으면, 그 파일을 기가파일(GigaFile) 같은 파일 전송 사이트에 올리고 **의견 보내기** 에 **그 링크** 와 **변환한 파일을 받으실 이메일 주소** 를 적어 주세요. 새 형식으로 바꿔서 보내 드립니다.
