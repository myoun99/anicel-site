# 열기와 저장

왼쪽 위 **프로젝트**(폴더 아이콘) 메뉴에서 합니다.

## 프로젝트 파일

- Anicel 의 프로젝트는 **`.anicel` 파일 하나** 입니다. 그림 · 타임시트 · 소리 · 설정이 모두 이 안에 들어갑니다(소리 · 영상을 「참조」로 둔 경우는 원본 파일이 따로 필요합니다 → [미디어 패널과 임포트](/ko/media-pool)).
- 여러 프로젝트를 열면 위쪽 띠에 탭으로 나란히 놓입니다.

## 열기

![](img/menu-project.png ':size=245')

**프로젝트** → **파일 열기**(또는 파일을 창에 끌어다 놓기). 무엇을 여느냐에 따라 알아서 갈 곳이 정해집니다.

| 파일 | 열리는 곳 |
|---|---|
| `.anicel` · `.tvpp`(TVPaint) · `.clip`(CLIP STUDIO PAINT) | 새 프로젝트 탭 |
| 이미지 · 동영상 · 소리 · PDF | [임포트 창](/ko/media-pool) |
| `.abr` · `.sut` · `.sutg` · `.anibrush` | [브러시](/ko/brushes) 라이브러리 |
| `.ttf` · `.otf` · `.ttc` | 글꼴([텍스트 도구](/ko/tools)) |
| 다른 앱의 단축키 파일 | [단축키](/ko/shortcuts) 프리셋 |

- **폴더 열기**: 컷 폴더(그림 파일이 든 폴더)를 통째로 임포트 창으로 엽니다.
- **최근 프로젝트**: 최근에 연 파일. 옮겨져서 못 찾는 파일은 **다시 연결** 로 새 위치를 알려 줍니다.
- 파일을 [뷰어](/ko/screen)에 끌어다 놓으면 프로젝트로 열지 않고 그 뷰어에 띄웁니다.

### TVPaint · CLIP STUDIO 파일

- `.tvpp` 를 열면 레이어 · 타이밍 · 중간 표시가 Anicel 의 레이어 · 블록 · 마크로 바뀝니다.
- `.clip` 을 열면 애니메이션 셀이 레이어 · 블록으로, 셀의 레이어는 [어태치 레이어](/ko/attach-layers)(A · A-1 …)로 들어옵니다.
- 원본 파일은 바뀌지 않습니다. 저장하면 `.anicel` 로 저장됩니다.

## 저장

| 메뉴 | 키 | 내용 |
|---|---|---|
| 저장 | <span data-k="file-save"></span> | 처음 저장할 때만 위치와 이름을 묻습니다 |
| 다른 이름으로 저장 → 프로젝트(.anicel) | <span data-k="file-save-as"></span> | 다른 파일로 |
| 다른 이름으로 저장 → PNG · JPG · BMP · TGA · TIFF … | | **지금 프레임 한 장** 을 캔버스 크기 그림으로 |

여러 장 · 동영상 · 셀로 내보내는 것은 [출력](/ko/export)입니다.

## 자동 저장

**자동 저장은 처음에는 꺼져 있습니다.** 꺼져 있으면 프로젝트는 저장할 때만 바뀌고, 앱이 비정상 종료되면 마지막 저장 뒤의 작업이 사라집니다.

- [환경설정](/ko/preferences) → **자동 저장** 을 켜고 **주기**(3~60분, 처음 값 10분)를 정하면, 그 주기마다 프로젝트 파일이 저장됩니다.

## 저장이 안 될 때 (실패본)

다른 프로그램이 파일을 쓰고 있거나, 읽기 전용이거나, 공간이 부족하거나, 드라이브가 빠졌을 때는 저장에 실패하고 이유가 표시됩니다.

- 그때까지의 작업은 앱 안의 **실패본** 에 저장해 둡니다. **실패본은 앱을 닫으면 사라집니다.**
- 남기려면 **프로젝트** → **실패본 백업** 으로 원하는 곳에 저장하거나, **다른 이름으로 저장** 합니다.
- 원인이 없어진 뒤 다시 저장하면 원래 파일에 저장됩니다.
- 열어 둔 프로젝트의 파일이 지워지거나 옮겨지면 알려 줍니다. 휴지통에 있으면 그때 되살리세요.

## 클라우드 · 태블릿에서

한 파일은 한 탭에서만 엽니다. 다른 탭에서 열려 있는 파일로는 저장하지 않습니다.

| | PC<br>(Windows · Mac · Linux) | iPad · iPhone | Android |
|---|---|---|---|
| **드라이브 · Dropbox 의 파일 열기** | 데스크톱 앱(Linux 는 동기화 도구)이 PC 에 만든 폴더에서 | 파일 앱의 드라이브 · Dropbox · iCloud Drive 에서 — 받는 동안 「클라우드에서 내려받는 중 · N초」 | 파일 창의 드라이브 · Dropbox 에서 — **작업본** 으로 열고, 저장할 때마다 파일 전체를 다시 올립니다 |
| **폴더 창에서 Google 드라이브** | 고를 수 있습니다(데스크톱 앱의 드라이브 폴더) | **못 고릅니다** — 「열기」가 눌리지 않습니다. iCloud Drive · Dropbox · 이 기기를 쓰세요 | **못 고릅니다** — 목록에 없습니다. 이 기기의 폴더를 쓰세요 |
| **권한** | 따로 없습니다 | 고른 파일 · 폴더만 그때 허락됩니다 | 파일 · 폴더를 고르기 전에 **모든 파일 접근** 을 켜야 합니다 |

- **폴더 창** 이 뜨는 곳: **폴더 열기** · 임포트 창의 **컷 폴더** · 미디어 패널의 **폴더에서 찾기** · Android 의 여러 장 출력.
- 출력을 드라이브에 내는 것은 → [출력 › Google 드라이브에 바로 내기](/ko/export?id=google-드라이브에-바로-내기)
