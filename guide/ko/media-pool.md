# 미디어 패널과 임포트

**미디어 패널**(미디어 풀)은 프로젝트에 가져온 이미지 · 소리 · 영상 · PDF 를 모아 두는 곳이고, **임포트 창** 은 파일을 들여올 때 어디에 어떻게 넣을지 정하는 창입니다.

## 임포트 창

파일을 창에 끌어다 놓거나 **프로젝트** → **파일 열기** / **폴더 열기**, 또는 미디어 패널의 **＋**(임포트)로 엽니다.

- 맨 위 줄: 고른 폴더를 **컷**(폴더 전체를 컷 하나로) 으로 넣을지 **커스텀**(줄마다 넣을 곳을 따로)으로 넣을지, 새 컷을 만들 때의 **컷 이름**.
- 파일 하나가 한 줄입니다. 열: 이름 · 수정일 · 크기 · 해상도, 그리고 줄마다 정하는 것:

| 열 | 고르는 것 |
|---|---|
| **넣을 곳** | 새 레이어 · 새 컷 · SE 행 · 미디어(패널에 등록만) · 제외 · 「줄 · n번 칸」(이미 있는 줄의 그 칸) |
| **래스터라이즈** | 켬(캔버스 그림으로 굽기) / 끔(파일을 가리키는 [참조 이미지](/ko/image-layers)) |
| **파일** | **품기**(프로젝트 파일 안에 담기) / **참조**(바깥 파일을 가리키기) |
| **맞춤** | 원본 크기 · 비율 유지 늘림 · 비율 무시 늘림 |
| **옵션** | PSD: 레이어 보존 / 합치기 · 동영상: 그림+소리 / 그림만 / 소리만 · 연번 그림: 범위 |

- 오른쪽 미리보기에서 동영상 · 연번 그림의 **IN / OUT**(쓸 범위)을 정합니다.
- 문제가 있으면 아래에 **경고 n가지** 가 뜹니다(예: PSD 의 잠금처럼 가져오지 못한 것).
- 동영상의 프레임레이트가 프로젝트와 다르면 프로젝트를 동영상에 맞출지 묻습니다(소리 타이밍은 유지).
- 그림이 든 **컷 폴더** 를 열면 폴더 구조대로 컷 · 레이어가 만들어집니다. 그림이 한 장인 줄은 이미지 레이어, 여러 장이면 애니메이션 레이어로 정해지고, 줄의 종류 칸에서 바꿀 수 있습니다.

## 미디어 패널

![](img/media-pool.png)

화면 오른쪽 띠의 **미디어** 버튼으로 엽니다.

- 줄마다 **품음 / 참조** 표시와, 그 미디어를 **쓰는 곳**(누르면 그 자리로)이 보입니다.
- **배치**: 줄의 **⋮ → 배치**, 또는 줄을 끌어다 타임라인 · 캔버스 · [콘티 패널](/ko/storyboard) · 뷰어에 놓습니다. 그림을 [타임시트 · 콘티 용지](/ko/sheets)의 칸에 놓으면 사진으로 들어갑니다.
- **⋮** 메뉴: 뷰어에서 열기 · 서브 뷰어에서 열기 · 배치 · 이름 변경 · 다시 연결 · 프로젝트 파일에 품기 · WAV로 내보내기(소리) · 미디어 삭제.
- 쓰이고 있는 미디어를 지우면, 배치한 것도 함께 지워진다고 먼저 묻습니다.

## 참조 파일을 못 찾을 때

참조로 둔 원본 파일이 옮겨지거나 지워지면 패널 위에 **못 찾은 파일 n개** 가 뜹니다.

- **폴더에서 찾기**: 파일이 옮겨 간 폴더를 고르면 그 안에서 찾아 몇 개를 찾았는지 알려 주고, 다시 이을지 묻습니다.
- 하나씩은 줄의 **⋮ → 다시 연결**.
- 다른 기기로 옮길 프로젝트는 **프로젝트 파일에 품기** 로 원본을 담아 두면 안전합니다.

## 뷰어에 필기하기

뷰어 위쪽의 **브러시 허용** 을 켜면, 품은 그림 · 동영상 · PDF 페이지 위에 바로 필기할 수 있습니다.
