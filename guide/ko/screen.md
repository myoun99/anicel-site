# 화면과 패널

![](img/overview.png)

## 화면의 다섯 부분

| 자리 | 무엇이 있나 |
|---|---|
| **위쪽 띠** | **프로젝트**(폴더 아이콘) 메뉴 · **설정**(⚙) 메뉴 · 캔버스/뷰어 전환 · 열려 있는 프로젝트 탭 |
| **왼쪽 세로 막대** | 실행 취소 · 다시 실행 · 어니언 스킨 · 선택 해제 · 확정 · 솔로 버튼, 그 아래 [도구](/ko/tools) |
| **양옆 띠** | 패널 버튼. 누르면 그 패널이 캔버스 옆에 열립니다 |
| **가운데** | **캔버스**(그리는 곳) 또는 **뷰어**(동영상 · 그림 파일을 보는 곳) |
| **아래쪽** | **타임라인** 패널과 **콘티** 패널 |

## 패널 열고 닫기

- 양옆 띠의 버튼 하나가 **패널 그룹** 하나입니다. 누르면 열리고, 다시 누르면 닫힙니다. 여러 그룹을 한꺼번에 열 수 있고, 열린 그룹은 위에서 아래로 쌓입니다.
- 버튼에 마우스를 올리면 그 그룹에 든 패널 이름이 뜹니다.
- 처음 설치했을 때 열려 있는 것은 왼쪽 **도구 라이브러리** 와 오른쪽 **타임시트 · 콘티 용지 · 컷 봉투** 입니다.
- 패널을 화면에서 아예 빼거나 다시 넣는 것은 **설정**(⚙) → **패널** 에서 체크합니다.

## 패널 옮기기

- 패널 위쪽의 **탭**(아이콘)을 끌어 다른 그룹의 탭 줄에 놓으면 그 그룹으로 옮겨 갑니다. 같은 줄 안에서 끌면 순서가 바뀝니다.
- 탭을 양옆 띠의 **＋**(새 패널 그룹) 칸에 놓으면 그 패널만 든 새 그룹이 생깁니다. 띠 하나에 그룹은 여덟 개까지입니다.
- 탭이 줄에 다 안 들어가면 끝에 **+N** 이 붙습니다. 누르면 나머지가 보입니다.
- 캔버스 탭은 고정되어 있어 옮겨지지 않습니다.
- 배치를 처음 상태로 되돌리려면 **설정**(⚙) → **패널** → **작업공간 배치 초기화** 입니다.

## 크기 바꾸기

![](img/resize-side.png)

- 열린 패널의 캔버스 쪽 가장자리를 끌면 너비가, 패널 사이 경계를 끌면 높이가 바뀝니다. 모서리를 끌면 둘 다 바뀝니다.

![](img/resize-bottom.png)

- 아래쪽 타임라인 · 콘티 영역도 위쪽 가장자리를 끌어 높이를 바꿉니다. 탭 줄 끝의 **접기** 를 누르면 낮게 접히고, **펼치기** 로 돌아옵니다(단축키 **타임라인 영역 접기 / 펼치기**).

## 가운데: 캔버스와 뷰어

- 위쪽 띠의 **캔버스 / 뷰어** 전환으로 가운데에 무엇을 둘지 고릅니다. 다른 패널을 가운데로 끌어다 놓았다면 그 패널도 여기에 나옵니다.
- **뷰어** 는 동영상 · 그림 파일을 그림과 따로 띄워 보는 곳입니다(레퍼런스 영상 등). **서브 뷰어** 는 같은 일을 옆 패널에서 합니다. 파일은 뷰어에 끌어다 놓거나 [미디어 패널](/ko/media-pool)에서 **뷰어에서 열기** 로 엽니다.

## 배치 바꾸기 (설정 → 패널)

![](img/menu-window-panels.png ':size=496')

| 항목 | 하는 일 |
|---|---|
| **툴 바를 오른쪽에** | 도구 막대를 캔버스 오른쪽으로 옮깁니다 |
| **타임라인 영역을 위로** | 타임라인 · 콘티 영역을 화면 위쪽에 둡니다 |
| **브러시 값을 상단띠로** | 캔버스 왼쪽의 브러시 크기 · 불투명도 알약을 위쪽 띠로 옮깁니다 |
| **전체 창 모드** | (데스크톱) 창을 화면 전체로 씁니다 |
| **작업공간 배치 초기화** | 패널 배치를 처음 상태로 |

## 프로젝트 탭

- 프로젝트를 여러 개 열면 위쪽 띠에 탭으로 나란히 놓입니다. 탭을 눌러 오가고, **✕** 로 닫습니다.
