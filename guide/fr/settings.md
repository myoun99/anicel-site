# Réglages du projet

Les deux premières lignes du menu **Paramètres** (⚙) s'appliquent **à ce projet seulement** (elles sont enregistrées dans le fichier). Ce qui s'applique à toute l'application est dans [Préférences](/fr/preferences).

## Réglages de l’œuvre

![](img/work-settings.png ':size=460')

- Le titre et l'épisode s'impriment en tête de la feuille de temps, de la feuille de conte et de l'enveloppe de plan.
- L'**Image de couverture** se choisit parmi les images du [panneau Médias](/fr/media-pool).
- **Équipe** : qui est responsable de chaque étape. Si cela diffère selon le plan, réglez-le dans la pilule **Plan** → **Réglages du plan**.

## Réglages du projet

![](img/menu-project-settings.png ':size=496')

Chaque ligne affiche sa valeur actuelle ; appuyez dessus pour la fenêtre qui la change.

| Ligne | |
|---|---|
| **FPS** | Dans un projet avec du son, la changer comme 23.976 ↔ 24 demande que faire du son : **Garder le timing audio** / **Tirer l'audio de 0,1 %** |
| **Fréquence d'échantillonnage** | 44.1 · 48 · 96 kHz |
| **Caméra** | La taille du cadre caméra (commune au projet). Vous pouvez aussi la faire glisser sur le canevas avec **Ajuster sur la toile**. Le canevas (le papier sur lequel vous dessinez) a sa propre taille pour chaque plan → [Taille du canevas par plan](/fr/canvas-size) |
| **Mode de lecture** | À une image dont le dessin n'est pas prêt : **Toutes les images** (par défaut) · **Sauter des images** · **Rendu avant lecture** → [Lecture et enregistrement](/fr/playback) |
