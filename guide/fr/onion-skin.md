# Pelure d'oignon

Dessinez en voyant les dessins d'avant et d'après posés légèrement sur celui-ci. Elle s'active **par calque** (il n'y a pas d'interrupteur global).

| Où | |
|---|---|
| ![](img/icon-rail-onion-skin-button.png ':class=icon :no-zoom') Haut de la bande d'outils | Le calque courant<span data-k="onion-skin-toggle" data-k-paren></span> |
| La case **Pelure d'oignon** d'une ligne de calque | Ce calque. Appuyez et balayez vers le haut ou le bas pour plusieurs lignes à la fois |
| La case pelure d'oignon de la ligne du haut de l'en-tête | **Appliquer la pelure d'oignon aux calques affichés / Retirer la pelure d'oignon des calques affichés** |

Elle fonctionne sur les calques d'animation, storyboard et direction.

## Le panneau Pelure d'oignon

| | |
|---|---|
| ![](img/icon-rail-group-rail-R4.png ':class=icon :no-zoom') | Le bouton de la bande de droite (partagé avec Taille de l'outil). Ce que vous réglez ici est un réglage de l'application, le même pour tous les projets |

![](img/panel-onion-skin.png ':class=panel')

- Le ● du milieu est le dessin courant ; les 8 de gauche viennent **avant**, les 8 de droite **après**.
- **La hauteur d'une barre = sa force**. Faites-la glisser vers le haut ou le bas (au départ 40 % avant, 30 % après).
- Appuyez sur le nombre sous une barre pour désactiver seulement celle-ci ; appuyez de nouveau pour retrouver sa force.

| Boutons du haut | Ce qu'ils choisissent |
|---|---|
| **Blocs** / **Images** | Si un cran = un dessin ou une image |
| **Couleurs** / **Dessins** | Fantômes en couleurs fixes / dans les couleurs propres des dessins |
| **Sur place** (par défaut) / **Au-dessus** | Glissés juste sous le dessin de chaque calque (couverts par les calques au-dessus, en suivant la fusion, le dossier et l'écrêtage de ce calque) / au-dessus de tous les calques |
| Cercles rouge · vert | Les couleurs des dessins d'avant et d'après, avec Colors |

## Pour voir un autre calque en transparence

La pelure d'oignon montre les dessins d'avant et d'après sur le calque lui-même. Pour utiliser le dessin d'un autre calque comme crayonné de fond, laissez ce calque affiché et baissez son **opacité**.
