# Preferences

**Settings** (⚙) → **Preferences**<span data-k="edit-preferences" data-k-paren></span>. They apply **to the whole app on this device** and do not go into project files.

## Input

![](img/prefs-input.png ':size=720')

Each of them is in [Touch and pen](/en/touch-pen).

## Autosave

![](img/prefs-autosave.png ':size=720')

- **It is off at first.** → [Opening and saving](/en/files)
- **App container**: how much the app keeps outside the project files.

## Audio

![](img/prefs-audio.png ':size=720')

- **A/V offset**: shows the picture later or earlier than the sound (makes up for wireless earphones). Check it with the **Sync inspector** while you set it.
- **Noise suppression** is for voice — turn it off when recording sound effects.
- How to record is in [Playback and recording](/en/playback).

## Language

![](img/prefs-language.png ':size=720')

The **Notation language** is the one printed on what you hand in, such as the timesheet. You can use the app in Korean and still turn in sheets in Japanese.

## Display

![](img/prefs-display.png ':size=720')

- **Cursor**: Brush / Pen / Crosshair. Brush shows the brush tip's shape.
- **Mark of an unnamed block**: the mark an unnamed drawing gets (○ In-between Mark 1 / ● In-between Mark 2).

## System

Shows how each part of the app is running right now. When something runs on a fallback, it works but is usually slower.

## Memory

![](img/prefs-memory.png ':size=720')

The **App allowance** is the ceiling on the memory the app may use. At first it is set automatically to suit the device; the button beside it returns to that value.
