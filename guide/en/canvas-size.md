# Canvas size per cut

Each cut can have its own canvas size. For example, make only the cut that needs a long PAN background wider.

![](img/canvas-size.png)

- Press **Cut** at the top of the timeline → open **Canvas size**. It applies to the current cut, and if it is a [linked cut](/en/linked-cuts), the cuts linked to it change too.
- Pick from the **Presets** (A4 150 · 200 · 300 dpi, HD · FHD · 2K · 4K) or type a width and height, and pick in the 3×3 grid where the existing drawing stays put.
- Press **Adjust on canvas** and the window closes so you can drag the edges of the canvas to resize it. The edge opposite the one you drag stays put; confirm with the check mark or Enter.
- The camera moves along with the drawing, so what the frame shows stays the same when you resize.
