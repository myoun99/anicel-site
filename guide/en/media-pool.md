# Media pool

Where the images, sounds, movies and PDFs you bring in are kept.

![](img/media-pool.png)

- Open it with the **Media** button on the bar at the right edge. **＋** (Import) picks files and only registers them, through the **Import** window.
- Place a file with **⋮ → Place…** on its row, or drag the row onto the timeline, the canvas, the [conte](/en/storyboard) or a viewer. An image dropped on a cell of the [timesheet or conte sheet](/en/sheets) goes in as a photo.
- **In the project** means the file is kept inside the project file; **Linked** means it points to a file outside. This is chosen in the **File** column of the Import window.
- **⋮** has Open in Viewer, Rename, Relink…, Keep inside the project file and **Delete media**. Deleting media that is in use asks first, since what you placed is deleted with it.
- Turn on **Allow Brush** at the top of the viewer to write straight onto images, movies and PDF pages kept in the project.
