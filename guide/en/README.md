# Anicel

An app for hand-drawn animation that keeps everything — conte, drawings, timesheet, sound and output — in one file.

## Strengths

- **Draw the conte and it already is the cut** — [Conte](/en/storyboard)
- **Work on the timesheet and conte sheet exactly as they will print** — [Timesheet & conte sheet](/en/sheets)
- **See each stage at a glance, by colour** — [Colour labels](/en/layer-labels)
- **Shadows and highlights ride the drawing they belong to** — [Attach layers](/en/attach-layers)
- **A different canvas size for each cut** — [Canvas size per cut](/en/canvas-size)
- **Sound as a layer, timed against its waveform** — [Sound layers](/en/sound-layers)
- **Movies, cels, timesheets and conte sheets from one export window** — [Export](/en/export)

New here? Start with [Getting started](/en/start).
