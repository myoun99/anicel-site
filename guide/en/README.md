# Anicel

An app for making hand-drawn animation. One project is one file.
The same file opens on Windows, macOS, iPad, Android and Linux.

[](../../launch/latest/en/notice.md ':include')

From storyboard to compositing, a cut is worked on in one project file. In this version, **in-betweening, finish and compositing** do not yet have everything it takes to fully replace dedicated software; features keep growing with each update. If there is a feature you want or anything you would like to tell us, send it through [**Send Feedback**](/en/feedback) (in the ⚙ Settings menu) — we will give it serious consideration.

- Keep many cuts in one project, each with its own canvas size — [Canvas size per cut](/en/canvas-size)
- Layers: animation, storyboard, image, folder, adjustment, SE, direction, camera and transition, plus attaches that ride a base layer — [Layers at a glance](/en/layers)
- Put color labels and takes on layers and cuts — [Color labels and takes](/en/layer-labels)
- See the timesheet, conte sheet and cut envelope while you work, and export them — [Timesheet, conte sheet, cut envelope](/en/sheets)
- Lay sound files on SE layers, and record with the microphone — [Sound (SE) layers](/en/sound-layers) · [Playback and recording](/en/playback)
- Import CLIP STUDIO (.sut) and Photoshop (.abr) brushes — [Brushes](/en/brushes)
- Open TVPaint (.tvpp) and CLIP STUDIO (.clip) files as projects — [Opening and saving](/en/files)
- Export movies (MP4, MOV), image sequences, cels, timesheets and conte sheets (PDF) — [Export](/en/export)
