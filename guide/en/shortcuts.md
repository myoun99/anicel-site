# Shortcuts

These are the default keys. They sit within reach of the left hand, and the arrows and **W A S D** do the same thing.

## Moving

| Action | Key |
|---|---|
| Layer Up | <kbd>↑</kbd> or <kbd>W</kbd> |
| Layer Down | <kbd>↓</kbd> or <kbd>S</kbd> |
| Previous Block | <kbd>←</kbd> or <kbd>A</kbd> |
| Next Block | <kbd>→</kbd> or <kbd>D</kbd> |
| Previous Frame | <kbd>Shift</kbd> + <kbd>←</kbd> or <kbd>Shift</kbd> + <kbd>A</kbd> |
| Next Frame | <kbd>Shift</kbd> + <kbd>→</kbd> or <kbd>Shift</kbd> + <kbd>D</kbd> |

## Playback

| Action | Key |
|---|---|
| Play / Pause | <kbd>Shift</kbd> + <kbd>X</kbd> |
| To Start | <kbd>Shift</kbd> + <kbd>Z</kbd> |

## View

| Action | Key |
|---|---|
| Zoom In | <kbd>Shift</kbd> + <kbd>E</kbd> |
| Zoom Out | <kbd>Shift</kbd> + <kbd>Q</kbd> |
| Toggle Onion Skin | <kbd>Q</kbd> |
| Solo active layer | <kbd>T</kbd> |

## Editing and tools

| Action | Key |
|---|---|
| Edit (the [Edit button](/en/timeline?id=the-edit-button)) | <kbd>X</kbd> |
| Lasso Select | <kbd>Z</kbd> |

## Good to know

- **On the X-sheet the arrows turn with the sheet.** Switch the timeline to the X-sheet (vertical) with **⇄** at the right end of its top bar, and <kbd>↑</kbd> <kbd>↓</kbd> (W S) go to the previous and next block, <kbd>←</kbd> <kbd>→</kbd> (A D) to the layer below and above, and <kbd>Shift</kbd> + <kbd>↑</kbd> <kbd>↓</kbd> (W S) to the previous and next frame.
- **Play, To Start and Edit press the button of the panel you touched last.** On the [conte](/en/storyboard) panel, Play plays the whole track, To Start goes to the track's start, and Edit opens the window for the block under the cursor (a cut's name, for a cut).
- **While you type in a text field**, such as a name, these keys type letters instead.
- **Every key can be changed.** **Settings** (gear) at the top left → **Keyboard shortcuts…** lists them all. A key you set yourself wins over the default.
