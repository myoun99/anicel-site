# Shortcuts

These are the default keys. The arrows and **W A S D** do the same thing.

## Moving

| Action | Key |
|---|---|
| Layer Up | <kbd>↑</kbd> or <kbd>W</kbd> |
| Layer Down | <kbd>↓</kbd> or <kbd>S</kbd> |
| Previous Block | <kbd>←</kbd> or <kbd>A</kbd> |
| Next Block | <kbd>→</kbd> or <kbd>D</kbd> |
| Previous Frame | <kbd>Shift</kbd> + <kbd>←</kbd> or <kbd>Shift</kbd> + <kbd>A</kbd> |
| Next Frame | <kbd>Shift</kbd> + <kbd>→</kbd> or <kbd>Shift</kbd> + <kbd>D</kbd> |

## Commas

| Action | Key |
|---|---|
| Set 1 Comma | <kbd>1</kbd> |
| Set 2 Commas | <kbd>2</kbd> |
| Set 3 Commas | <kbd>3</kbd> |
| Set 4 Commas | <kbd>4</kbd> |
| Set N Commas… | <kbd>5</kbd> |

- The same as the **1 2 3 4 N** buttons at the top of the timeline and conte panels. They set the length of every selected block (the current block when nothing is selected), and the blocks after it close up or move along — select all of `1--2--3--`, press <kbd>1</kbd>, and it reads `123`.
- <kbd>5</kbd> opens a window to type the count.

## Good to know

- **On the X-sheet the arrows turn with the sheet.** Switch the timeline to the X-sheet (vertical) with **⇄** at the right end of its top bar, and <kbd>↑</kbd> <kbd>↓</kbd> (W S) go to the previous and next block, <kbd>←</kbd> <kbd>→</kbd> (A D) to the layer below and above, and <kbd>Shift</kbd> + <kbd>↑</kbd> <kbd>↓</kbd> (W S) to the previous and next frame.
- **Play, To Start, Edit and the comma keys press the button of the panel you touched last.** On the [conte](/en/storyboard) panel, Play plays the whole track, To Start goes to the track's start, Edit opens the window for the block under the cursor (a cut's name, for a cut), and the comma keys set that block's length (the cut's length, for a cut block).
- **Every key can be changed.** **Settings** (gear) at the top left → **Keyboard shortcuts…** lists them all. A key you set yourself wins over the default.
