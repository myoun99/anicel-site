# Project settings

The top two rows of the **Settings** (⚙) menu apply **to this project only** (they are saved in the file). What applies to the whole app is in [Preferences](/en/preferences).

## Work settings

![](img/work-settings.png ':size=460')

- The title and episode are printed at the head of the timesheet, conte sheet and cut envelope.
- The **Cover picture** is picked from the pictures in the [media panel](/en/media-pool).
- **Staff**: who is in charge of each stage. If it differs by cut, set it in the **Cut** pill → **Cut settings**.

## Project settings

![](img/menu-project-settings.png ':size=496')

Each row shows its value now; press it for the window that changes it.

| Row | |
|---|---|
| **FPS** | In a project with sound, changing it as in 23.976 ↔ 24 asks what to do with the sound: **Keep audio timing** / **Pull audio 0.1%** |
| **Sample rate** | 44.1 · 48 · 96 kHz |
| **Camera** | The size of the camera frame (shared by the project). You can also drag it on the canvas with **Adjust on canvas**. The canvas (the paper you draw on) has its own size for each cut → [Canvas size per cut](/en/canvas-size) |
| **Playback mode** | At a frame whose drawing isn't ready: **Every frame** (default) · **Skip frames** · **Render first** → [Playback and recording](/en/playback) |
